# 鼻腔建模与 CFD 分析

本仓库保存鼻腔建模项目的可复现代码、配置、方法文档、检查报告和演示页。

## 目录

- `演讲展示页/`：项目演示页及其轻量模型资源
- `资料/`：需求、SOP、方法说明和项目记录
- `检查结果/`：数据可用性检查脚本与报告
- `work/`：建模、标定、CFD 和自动化流程中的代码、配置与验证文档

## 数据与本地软件

患者影像、DICOM/NRRD 数据、模型大文件、运行缓存和 Blender/ParaView/3D Slicer 安装目录未纳入 Git 仓库。`.gitignore` 保留这些本地资产在工作区中，同时避免把敏感数据、可再生输出和超过 GitHub 单文件限制的文件推送到远程仓库。

## 演示页

在本地静态服务器中打开 `演讲展示页/index.html` 即可查看演示。页面依赖同目录下的 `assets/` 资源。

## 快速打开工作台

双击项目根目录的 `打开鼻腔建模工作台.cmd`，或使用桌面上的“鼻腔建模工作台”快捷方式。它会启动本地工作台并打开统一入口：`http://127.0.0.1:8769/workspace/index.html`。如果服务已经运行，会直接复用现有服务。

## 医学复核交接

工作台顶栏提供“导出医学复核包”和“导入医学复核反馈”。可勾选多个病例及复核阶段，一次下载包含多份离线 HTML 的压缩包；单份直接下载 HTML。医学复核人可逐项填写并导出反馈 JSON。收到反馈后，可在“意见核对”中查看、选择点位意见，再到切片页核对并保存。

操作与证据限制见 [医学复核使用说明](work/07_cfd_pipeline/医学复核使用说明.md)。复核包与反馈保存在本机，不纳入 Git。
