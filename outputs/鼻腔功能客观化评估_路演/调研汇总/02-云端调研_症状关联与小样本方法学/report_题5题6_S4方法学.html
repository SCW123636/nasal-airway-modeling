1. 题5：小样本无监督聚类的稳定性协议与门槛先例

Q5.1 稳定性指标与常用裁定门槛

结论（可执行）：门槛无跨领域统一值，本质是「工具默认值 + 领域惯例」。建议 S4 采用 Jaccard（每簇）≥ 0.75 作为"良好复原"线、≤ 0.5 判为"簇解体"，并可保留 ARI 作为补充但不与 Jaccard 混用同一门槛。

关键出处（原文核验，我直接读了 PDF）

  • Hennig C. 2007, Computational Statistics & Data Analysis 52(1):258–271（原文 PDF 已核验）。原文表述为：

"…of dissolutions (γ_C,i ≤ 0.5) or good recoveries (γ_C,i > 0.75, say) can be used as…"

注意 "say" —— 0.75 是举例性、非统计推导出的界；而 0.5 有理论依据：原文引 Hennig (2004c) 指出 1/2 是「簇在增点下解体」的临界值（"the value 1/2 as a critical value for so-called dissolution of a cluster"）。

  • clusterboot（R 包 fpc）默认参数：dissolution = 0.5、recover = 0.75、B = 100 —— 0.75 的广泛传播主要来自这个软件默认值。

其他口径【检索报告，未逐条读原文】

指标 门槛 出处 性质

【推断】 Jaccard 与 ARI 不是同一尺度（ARI 对簇数敏感、有校正随机一致性），不应把 0.75 同时套在两个指标上。

Q5.2 bootstrap 聚类稳定性标准协议

结论（建议落地参数）：B = 1000 次、80 % 子采样（无放回）、报告「每簇 Jaccard 均值 ± SD + 解体次数/复原次数」，并把 ARI 作为次级指标并列报告。

依据

  • Hennig 2007（【原文核验】）：提出 clusterboot 的非参 bootstrap 方案，输出为每簇 Jaccard 均值与 dissolution/recovery 计数；同时讨论了多重点的缺陷。
  • 【检索报告】Monti et al. 2003 共识聚类推荐子采样 80 %；常规工作流 reps = 1000, pItem = 0.8；clusterboot 默认 B = 100，vignette 用 B = 500。
  • 报告格式无强制规范，主流是「每簇 Jaccard 均值 + 解体/复原计数」，或「平均 ARI 分布」。

【推断（针对 n=24）】：n=24 时有放回 bootstrap 会产生大量重复点、小簇被过度稀释；建议改用 80 % 无放回子采样（Hennig 2007 亦提出 subsetting 作为替代重采样方案），并把每次子采样的簇数固定为原 k。

Q5.3 小样本下 k 的选择

结论：轮廓系数不可单独用于 n=24 定 k，须与稳定性联合；n/k 的"≥10"经验下限不适用于本场景，不可反过来用它论证"n=24 充分"。

依据

  • 【检索报告】轮廓系数惯例：>0.5 强 / 0.25–0.5 可用 / <0.25 视为无结构（Rousseeuw 1987 提出指标；阈值属惯例）。
  • 【检索报告】轮廓 + 稳定性 + 最小簇占比三者联合定 k 的先例存在，其中"最小簇占比 5 %"被用作风险线。
  • 【检索报告】n/k 经验值来源：Qiu & Joe (2009) 建议 n ≥ 10·p·k；Dolnicar et al. (2014) 建议 n ≥ 70·p（p = 变量数）——这些来自市场细分/变量数主导的场景，不是医学表型场景。

【推断（可直接执行的约束）】 n=24、p=4 时：

  • k 上限建议 3（最多 4）；每簇 ≥ 5–6 例；
  • n=24 明显低于「10·p·k」（k=3 → 需 120），应在方法学局限中如实声明，禁止反向引用 n/k 经验值来"论证充分"；
  • 轮廓系数要求每簇 ≥ 2 例，全单点解须排除。

Q5.5 稳定性不达标时的标准处理

结论：三条路线，优先推荐 ① 降级为连续特征描述。

路线 先例与取舍
① 降级为连续特征（首选） Dennis JM et al. 2019, Lancet Diabetes Endocrinol：明确结论「基于连续表型指标优于基于亚组分配」，因簇"非病因性、重叠、个体层面无法稳健界定"。先例最硬。
② 改模型型（LCA / LCMM） LCA 常规需 n 数百（Nylund 2007 最低 200；Wurpts & Geiser 2014「不建议 n<100」）；仅"简单、两类、分离良好"时 n 小至 30 或可。距离法 vs LCMM 对比研究显示 LCMM 常产生极小/虚假类。
③ 保留为探索性/假说 明确标注探索性质 + 外部验证计划

【推断（n=24 的直接裁定）】 LCA/混合模型在 n=24 下多数场合样本不足；最稳妥是 PCA 得分连续特征描述 + 明确标注假说生成，或仅报"描述性分型"并附外部验证计划。半监督方法未找到强先例。

2. 题6：跨研究指标协调与外部表型迁移

Q6.1 跨研究指标定义不一致时的对齐方法学

结论（可执行规则）

  1. ComBat 类特征协调只解决「同一物理量在不同批次/中心/协议下的技术性偏移」，不能解决「异指标映射」。 其模型把观测拆成「生物信号 + 站点加性 γ + 乘性 δ」，前提是各批次分布仅相差平移与缩放；WSS(Pa) 与热通量(W/m²) 与流量占比(%) 是不同物理量，不满足该前提。
  2. 协调变换不可外推：已发布的协调变换无法直接施加到未纳入的新中心新受试者。因此 n=24 新队列 → 文献表型的单向映射，不能靠 ComBat 完成。
  3. 应区分四类不一致：测量截面 / 归一化 / 单位 / 边界条件。前三类须先做物理层统一（重采样、单位换算、统一定义）；第四类（BC）无法统计校正，只能做敏感性分析。

Q6.3 异质效应量（r 值）的证据合成

结论

  1. 仅当 PICO + 效应量同尺度且临床/方法学同质时才做正式 meta；否则用 SWiM（无 meta 的合成） 并透明报告"为什么没做 meta"。
  2. 相关系数须先 Fisher z 变换再合并：Var(z) ≈ 1/(n−3)，权重 w = n−3；假设每研究内双变量正态、研究独立；须同时报 z（含 SE）与回变换 r。
  3. 证据分级：CFD 指标异质且无共同参照标准，S4 的合成应定位为 OCEBM 诊断链 Level 4–5、GRADE low / very low。

出处【检索报告】

  • GRADE 工作组 SWiM 指南（usblog.gradeworkinggroup.org）：无效应量可算或存在实质异质（临床/方法/统计）时用叙述性合成；常见错误是不披露"未做 meta"。
  • WHO 康复系统综述方法学建议（PMC10684421）：临床同质性高才考虑 meta，否则 SWiM。
  • Fisher z 合并：Hedges & Olkin 1985；要求 n>10、研究独立。
  • OCEBM 2011 Levels of Evidence（CEBM 官方 PDF）：诊断问题 Level 1 = 参照标准一致且盲法的横断面研究的系统综述；Level 5 = mechanism-based reasoning。推荐等级 A = 一致 Level 1；D = Level 5 或任何级别不一致/不确定。

【推断】 委托方已有的 6 条区域相关量（r 从 −0.40 到 −0.76，n 从 10 到 30，BC 各异）不应合并为单一 pooled r；应做 SWiM 式叙述合成 + 逐条标注 n / BC / 指标定义 + 给出异质性说明。

Q6.4 阈值/模型迁移到新数据的禁区与最低验证

结论：迁移阈值/模型到不同边界条件的新数据不被接受，因为它绕过 TRIPOD 外部验证链。BC 差异属"case-mix / 分布漂移"，会同时破坏 calibration-in-the-large、calibration slope 与 O/E ratio；AUC 良好不能证明可用。

最低要求（可执行清单）

  1. 指定目标人群；
  2. 锁定阈值（不改 cut-off）；
  3. 报 discrimination + 校准（校准图、slope、intercept / O/E，均带 CI）；
  4. 必要时预设再校准，并在另一独立样本再验证。

TRIPOD+AI 2024 要求校准图 + calibration slope(理想 1) + calibration-in-the-large(理想 0) + O/E(理想 1)，各带 CI；避免 Hosmer–Lemeshow

儿科 SSI 模型迁移到 EHR（JAMIA 2026, doi:10.1093/jamia/ocag162） 直接套用致 c=0.60、校准斜率 0.15、O/E 0.25；指出「predictor misalignment（预测因子测量方式不同）是直接部署的关键障碍」
分布漂移量化（arXiv:2604.16537，预印本） KL 散度越大 ICI 越差；「外部校准成功不保证可迁移」

【推断】 把文献 WSS(Pa) 阈值套到入口温湿度 / 湍流模型 / 流量都不同的新数据，等价于一次未经校准的迁移，RQS-12 与 TRIPOD-12/13c 均要求拒绝或降级。对 S4 的直接含义是：阈值只能用于«定性方向对照»（如"越高越通畅"），不能用于«用量阈值判阳性»。

【未找到】 以"鼻腔 CFD 边界条件差异"为对象的专用迁移学方法学文献。

汇总：五篇的指标同构性风险点

  1. 指标哲学分裂：Zhao 用「局部峰值热损失」；Sullivan 用「>50 W/m² 的面积（cm²）」——两者不可互换。
  2. BC 不统一：仅 Casey 给固定 15 L/min；Sullivan 用「体重推算分钟通气量 ×2」；Zhao/Li/Maza 用 15 Pa 压降；黏膜温度 32.6 °C（Sullivan）vs 35 °C（Zhao）→ 热通量绝对值不可跨研究比。
  3. 湍流模型：Casey/Sullivan 层流；Li/Maza 未点明；跨研究比 WSS 存在系统性偏差风险。
  4. 截面/归一化各异：Casey D = 0.3/0.5/0.7（以鼻中隔长度归一化）；Li/Maza d = 0.6；Zhao 仅解剖描述 → 「中/下鼻道气流 %」的分母与位置不可直接对齐。
  5. 解剖实体混淆：Li/Maza 是「下鼻甲区（IT）」而非「下鼻道（inferior meatus）」——委托方登记表需更正。
  6. 年份错误：Zhao 实为 2014；Maza 卷期实为 2019。
  7. 对照组复用：Li「健康 42」与 Maza 的对照是同一批，不可当作独立证据累加。
