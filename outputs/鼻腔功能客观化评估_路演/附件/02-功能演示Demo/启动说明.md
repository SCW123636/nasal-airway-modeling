# 功能演示 Demo · 启动说明

## 启动（一条命令）

双击项目根目录下的 `work/07_cfd_pipeline/启动三维工作台.ps1`
（启动本地服务，仅监听本机回环地址，端口 8769）。

## 打开

- 唯一工作台入口：<http://localhost:8769/workspace/pro/index.html>
- 健康检查：<http://127.0.0.1:8769/health.json>（页面空白时先看这里）

## 建议演示动线（对应路演稿第 05–06 页）

1. **患者树**：三例真实患者（已脱敏），点选任意一例
2. **三维检查**：解剖切视页，查看气道几何与开口判据
3. **流线**：扩展域气流流线（111 条，出口参数化）
4. **对比**：两个三维模型并排双视口，共用相机轨道同步
5. **任务控制台**：网格 / 求解任务状态

## 口径提醒（随演示声明）

- 数值唯一来源：`pro/patient_metrics.json`（现行基线 T-058 §6）
- 三例为**稳态层流工程尺度验证**，非临床诊断；出口为扫描底工程截断面
- R 绝对值不可与临床鼻测压对标，仅配对相对变化可采信
