### ⚠️ 三个必须遵守的约束（踩过坑）

1. **`upsert-dsl` 的语义是「插入/追加」，不是「替换」。**
   在同一个 pptx 上重复写同一页不会覆盖，而是**追加出一页新的**，导致出现「上一代」重复页
   （本项目曾把 18 页写成 43 页）。**每次重建都必须从空白母版重新开始，只跑一遍。**
2. **必须用 `--page-index i`，且 `i` 从 0 开始严格 +1 递增。**
   默认的「追加」模式有 off-by-one：空文档上第 2 页即报
   `CommitRevision failed: page index out of range`。
3. **`lint` 只有加 `--visual` 时才接受 `--base-url`**；不带 `--visual` 时传会报
   `unknown option --base-url`。同理 `lint --visual` 会真正调用 VLM 打留白分，耗时长（约 50 秒/页）。
