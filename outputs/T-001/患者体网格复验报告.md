## 二、必答问题逐条判定

### 问题 ①：本地 `cellDeterminant` 能否修正到复现 checkMesh？

**判定：不可作判据，以 checkMesh 为准**（T-001-A 交付 `源码审计_cellDeterminant.md`）。

- **checkMesh 真实调用链**（任务卡曾写错，已更正）：
  `checkGeometry.C:865` → `polyMeshGeometry.C:2337` → `polyMeshGeometry.C:1989`
  （`polyMeshGeometry::checkCellDeterminant`）。
  **不在** `primitiveMeshCheck.C`；`primitiveMeshTools.C:456` 的「仅内部面」版本也不是本次通路。
- **公式**（`polyMeshGeometry.C:2014-2022`）：
  `areaSum = Σ_i |S_i|·(û_i û_iᵀ)`；`magAreaSum = Σ_i |S_i|`；
  `scaledDet = det(areaSum / magAreaSum) / 0.037037037037037`（×27，立方体归一到 1）。
  并矢 `ûûᵀ` 与面积矢量符号/朝向无关 → owner-neighbour 归属、面节点顺序、翻转**都不影响结果**。
- **参考二进制是定制构建**：日志文本 `(wellposedness)` / `(1 = uniform cube)` 措辞在整棵
  v1912.200626 源码树中**搜不到**（源码打印的是 `"Cell determinant (1 = uniform cube)"`）
  → 「完全可复现」的声明需留余地。
- **⚠️ 未决**：修正版公式**至今未经实证**（零 CPU 车道取不到 WSL 里的 polyMesh）。
  故只能写「以 checkMesh 为准」，**不得**写成「本地判据已证伪」——那是两回事。

### 问题 ②：`gmshToFoam` 的 112818 undefined faces 是缺陷还是提示？

**判定：转换器提示，非几何缺陷**（主对话核算，R6 结案）。

- 终态 `boundary` 仅 4 个 patch：`nostril_L 5020 + wall 86822 + nostril_R 3431 + nasopharynx_outlet 17545 = 112818`
  （出处 `outputs/T-001/logs/boundary.foam_repaired`），**无 `defaultFaces`**。
- checkMesh 报 `Boundary definition OK`、4 个 patch 拓扑全 `ok`。
- 未修复/修复、1.0/0.4 **四个网格报同一数字 112818** → 与几何修复无关，是转换器的常规提示。

### 问题 ③：残余 585 个 `<0.001` 如何消除？

**判定：加分辨率无效；须换「源头细分 + 换修复策略」并联**（T-001-B 交付 `findings_maxh对照.md`）。
