## 1) execution_allowed 由 readiness 决定（无论有无 errors）
cfd_contract.py:40-43
```
def _report(errors, warnings, execution_allowed=False):
    return {"valid": not errors, "errors": errors, "warnings": warnings,
            "execution_allowed": bool(execution_allowed and not errors),
            "validation_scope": "contract_metadata_and_inline_values_only"}
```

=> 结论：只要 readiness 非空（即使零 errors），`execution_allowed = not readiness = False`。
readiness 来自两类：(a) 患者几何审核元数据；(b) solver_adapter.status != "implemented_and_verified"。

## 2) 患者几何审核元数据要求
cfd_contract.py:115-142 （_patient_geometry_issues，节选关键项）
- geometry.case_id / source_file 必填
- geometry.sha256 须为 64 位 hex
- review.status == "confirmed" 且 method == "human"
- review.reviewer / reviewed_at / record_file 必填
- review.reviewed_geometry_sha256 == digest
- confirmed_boundaries 须含 {nostril_L, nostril_R, nasopharynx_outlet}
- oral_exclusion_confirmed == True
- sinus_boundary_policy_confirmed == True
