## 5. 压力（Δp）

**取压位置与方法**：各 patch 上的**面积加权平均静压** `areaAverage(p)`，由 `system/controlDict` 内 `surfaceFieldValue` 函数对象计算
（`postProcessing/pressure_nostril_L|R|nasopharynx_outlet/0/surfaceFieldValue_0.dat`）。

**关键口径**：`0/p` 维度为 `[0 2 -2 0 0 0 0]`，即**运动压力 p/ρ**；
Δp(Pa) = ρ × Δp(运动)，ρ = 1.2 kg/m³（配置 `physics.rho_kg_m3 = 1.2`）。
鼻咽出口 `nasopharynx_outlet` 为 `fixedValue 0`，面积平均静压 = 0。

| patch | 稳定段（@100 步，kinematic → Pa） | 发散段（@252→259，kinematic，已失稳） |
|---|---|---|
| nostril_L | 7.15085 → **8.58 Pa** | 252: -2.94e6 … 259: 5.86e26 |
| nostril_R | 9.32233 → **11.19 Pa** | 252: -4.1e4 … 259: -4.79e28 |
| nasopharynx_outlet | 0.0 → 0.0 Pa | 0.0 |

- **稳定段 Δp ≈ 8.6–11.2 Pa**（双鼻孔，运动压力×1.2），代表值 ≈ 10 Pa，恰在 plausibility 带 **10–100 Pa 的下沿**（右鼻孔入带、左鼻孔略低于下界）。
- **但该 Δp 仅为前 ~250 步的瞬态/准稳态值**：因求解最终发散（§4），它**不可作为可信的稳态压降结论**。从 252 步起压力失控（10² → 10²⁶ 量级）。
- 确切命令：求解时由 `controlDict` functions 自动输出；亦可事后复算：
  `postProcess -func "surfaceFieldValue(name=p_nostril_L, regionType=patch, name=nostril_L, operation=areaAverage, fields=(p))"` 等。

## 判定（明确结论）

**→ 不通过（发散）分支。M1 不应按「实测充分」收口；网格质量确实致命，应回头攻源头细分。**

论据：
1. **prescribed 路径不可用**：`run_openfoam_case.py` 在 `:469-472` 的 `tube.stl` hard-gate 结构性禁止在患者网格上跑「不合格网格诊断求解」；谎报来源违反「严禁编造」。实证数据只能经带外直接 `simpleFoam` 取得。
2. **带外求解先稳后崩**：maxh=1.0 修复网格（585 det<0.001 单元、114 低权面）上，simpleFoam **前 ~250 步稳定收敛**（Δp≈8–11 Pa，质量平衡 0.0008%）**但随后灾难性发散**，Time=260 `sigFpe` 崩溃。稳定段 Δp 虽贴近 plausibility 带下沿，却因最终发散而**不可信为稳态结论**。
3. **根因指向 determinant 缺陷**：发散与 585 个 det<0.001 单元区时间窗同步，印证 T-005「硬威胁是 determinant 而非低权重」——低权面仅降精度，det 缺陷在长时迭代后诱发数值失稳。
4. **严格留痕项**：
   - 网格级别不一致：配置 medium=maxh0.4，实测 maxh=1.0（已说明权衡）。
   - 18 Pa 口径争议未决，本报告严格未采用 `static_pressure_difference_*` / `recording_total0_staticplus18_*`。
   - `engineering_acceptance` 经唯一可用的 Run A manifest 回读为 **false**（满足逐字留痕）。
   - 全链路标注「链路验证，不得报告为患者分流结论」。

**对 M1 的建议**：维持「Mesh OK 门禁未达成」事实；实证显示该网格不能支撑可信稳态求解（发散），故**不应以「实测充分」收口**。应回到源头：修复 585 个 det<0.001 单元（优先于低权面治理），或按任务卡待选项改跑严格 medium（maxh=0.4，494 sliver）那套做对照复验。
