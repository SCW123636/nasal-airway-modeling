## 交付

1. **单一真源 `workspace/pro/tokens.css`**：一处定义 ink / muted / faint / line / line2 / soft /
   soft2 / accent / warn / bad / bg / panel / canvas / mono。pro 外壳与各接入页 `link` 引用；
   自包含单文件产物（`streamlines_*.html`）按同值内联并在样式头注明出处。
   文件头写明三条纪律：① chrome 一律单色（靠明度 + 字重 + 字形 + 底纹区分，不靠色相）；
   ② 颜色只留给数据本身（三维几何分类色 / 流场色带 / 图表数据系列，就地声明）；
   ③ 尺寸语言圆角 2–3px + 1px 描边 + 等宽标签。
2. **pro 工作台四页单色化**：`pro/pro.css` 删自身 `:root`；`t058_cut.html` / `t058_cmp.html`
   外链令牌并重写版式（提示框由琥珀改单色）；`streamlines_template.html` 同值内联；
   两份已落盘流线产物就地替换（样式段 + 内联绘图 chrome），**正文数据 sha256 逐字不变**。
3. **两个进度页构建器单色化**：`build_progress_cards.py` / `build_progress_dashboard.py` 的
   `:root` 换令牌同值；图例 emoji（✅⚠️⛔▶○）换成**文字 + 单色底纹**；状态词改为
   字重/斜体/下划线/底纹区分；`.todo/.block/.done` 色条改灰阶；「红底」行改灰底；圆角 10px → 3px。
4. **遗留工作台外壳与 03/06 步面板收敛**：`workspace.css`、`embedded.css`、`workbench-pro.css`、
   `boundary-review/index.html`、`viewer/viewer.css`、`viewer/viewer.js` —— 绿/蓝系 chrome 经
   **一对一角色映射**迁移到令牌（80 个键，穷举全部颜色字面量，不用阈值近似）。
5. **三维照明色中性化**：`t058_cut.js` / `t058_cmp.js` 的 `HemisphereLight` 地面色
   `0xa9b9c0` → `0xc8c8c8`、坐标轴 `0x23332f` → `0x1a1a1a`；`viewer.js` 的
   `HemisphereLight` `0x637981` → `0x6e6e6e`、补光 `0xbedee8` → `0xdcdcdc`。
   → 几何体不再带色偏，颜色只来自分类色本身。
