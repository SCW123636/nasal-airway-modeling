## 1. 合同范围与边界（复诵）

- 目标：从真实 CT 建立可审计的**连续空气空间工程对照**，核对原语义范围之外可提取的侧方/后下方空气；
  有可靠候选时提供工作台交互三维与 CT 对照。**截图未与任何 p 编号绑定，不声称精确复刻或医学正确。**
- 约束（合同第 8 条）：禁改原 CT/DICOM/标签、T026/T030/T032 产物、原分割与开孔裁剪逻辑、旧切面/阈值/医学或 CFD 准入；
  **不启动网格或 CFD**；不绕过 N6；不改变 T-011。
- 方法口径（合同第 13 条）：严格 CT < −300 HU、6-邻接、无造桥/填洞/插值延长；以真实鼻腔/鼻咽/口咽空气为种子；
  只能用有来源的现有阻断面或明确标注的工程探索域约束；**不能凭阈值连通把区域命名为鼻窦/下咽**，不能用最大分量静默删除原有分量。
- 判据（合同第 13 条末）：若外部空气泄漏或口腔污染无法可靠隔离，保留失败/完整诊断，**不调参硬凑目标或虚报可用**。

## 3. 方法（实现模块 `continuous_air_candidate.py`）

- 阈值严格 `CT < −300 HU`；连通 `ndimage.label(structure=generate_binary_structure(3,1))` 即 **6-邻接**。
- 所有种子分量保留，除非显式记录的阻断面（barrier）移除其体素；**无插值、无闭运算、无填洞、无人工桥接、无最大分量剪裁**。
- 阻断面为「候选」，状态均为 `proposed`（鼻孔 L/R 的 original / exploratory / parameter_delta），**未经医学审核**。
- 工程屏（`exterior_screen_limit`）：仅要求「无分量抵达侧方扫描面」作为必要非充分条件，**非**「全部外部空气已排除」的证明。

## 4. 结果（run02，status = `engineering_probe_completed`）

### 4.1 连通性事实
- `air_component_count = 32241`：整卷空气碎裂为 **32241 个互不连通分量**——**不存在单一连续气道**。
- 种子（原始语义空气）仅命中 **2 个分量** `seed_component_ids = [186, 20066]`；`seed_original_voxels = 445592`，`eligible_seed_voxels = 443870`，`seed_removed_or_nonair = 1722`。
- 候选合并后 `candidate_voxels = 1339813`，`added_vs_eligible_seed_voxels = 895943` —— **候选较原语义空气新增约 89.6 万体素，体量翻倍**，且 `candidate_component_sizes = [1339667, 146]` 显示合并分量被外部空气主导。

### 4.2 外部空气泄漏（逃逸路径）
- `escape-path.json`：`found_escape = true`，`visited = 1840`，路径 **70 步**，`start_zyx = [22,57,237]` → `end_zyx = [14,0,235]`。
- 终点 y 索引 = **0**，而网格 y 维 = **512** → 空气从前/下缘**抵达扫描体边界外泄**。
- `exterior_component_ids` 为长列表（数十个），即多个外部空气分量与种子区域相接。

### 4.3 新增范围与切面接触
- `added_extent.LPS_center_bounds_mm`：LPS 中心范围约 `[-47.18, -133.29, 281.29]` → `[40.57, -21.29, 374.29]`——显著超出原鼻腔/鼻咽语义域，向后下方与侧方延展。
- `new_cut_contact`：鼻孔 L 候选 `926` 体素邻接被排除半空间，鼻孔 R 同型——新增域与原开口切面强接触，无法用现有阻断面干净切离。

### 4.4 工程屏与准入
- `engineering_screen_pass = true`：**连通性方法本身合规**（严格阈值、6-邻接、无桥接/最大分量剪裁）。
- `CFD_admitted = false`、`outlet_selected = false`、`oral_exclusion_reviewed = false`、`medical_review = pending`、
  `symptom_patient_mapping = unknown`、`manual_STL_correspondence = unknown`。

## 5. 结论

**未能建立可靠的连续空气域候选。** 严格 −300 / 6-邻接从原始语义空气种子出发时，空气域碎裂为 32241 个分量，
且经前/下缘逃逸至扫描体边界外泄（70 步泄漏路径，y→0），候选被外部空气主导（新增 +895943 体素）。
这正触发合同第 13 条末款：**外部空气泄漏无法可靠隔离 → 保留完整诊断，不调参硬凑目标或虚报可用。**

- 本对照为**工程探索**，截图三处形态（侧方囊状、两近似平整端部、后下方长段）**未与任何 p 编号绑定、未声称精确复刻或医学正确**。
- **不授予 CFD 准入**、**不改变 T-011**、**不绕过 N6**、**不宣称已分出下咽/鼻窦**。
- 阻断面均为 `proposed`，**未经医学审核**；症状—病例映射 `unknown`；手工 STL 身份 `unknown`。
- `scope`（取自 artifact）：「engineering exploration; exterior ROI extension is not a medically reviewed cut」。
