# T-039 · SlicerVMTK `CFD Mesh Generator` 实测收卡（VERIFIED，负面结论）

**结论一句话**：这条链**能跑通**且拓扑完全干净（单区域/水密/体积逐位守恒），但在实测几何上
**默认参数两处必失败**（表面重网格把封闭面搞坏、边界层自折叠），只有「关重网格 + 关边界层」能出网格；
出网格过不了 `checkMesh` 5–6 项质量门、`det<0.001` 占比比患者 b15 差**一个量级**；
**Netgen 默认参数下质量与速度都不如 TetGen**（插值权差 7.8×、体积比差 63×、慢 13.5×）。
⇒ **不纳入本项目生产链候选**；现役 Netgen 管线（Netgen API 直调）继续使用。报告：`outputs/T-039/T-039_CFDMeshGenerator实测报告.md`（11 节，含全部原始报错与产物清单）。

## 3. 质量对照（`checkMesh -allGeometry -allTopology`，v1912）

- **三格共同通过**：拓扑六项 / 单区域水密 / 体积 8.86281e-05 m³ 与 STL 逐位守恒 / 凹面检查。
- **质量门**：Failed 6/5/6 项；`det<0.001` 占比 **0.94% / 0.58% / 0.90%**——患者 b15 为 **0.05%**，差一个量级；
  最大非正交 89.3–90.0° vs b15 87.3°。
- **尺寸效应（D vs E）**：体积尺寸贴表面尺寸可把最大长宽比 2106→130（OK）、Failed 6→5，但**消不掉 det<0.001** → 坏单元来自贴壁几何本身。
- **引擎效应（D vs F，唯一变量）**：`det<0.001` 与严重非正交几乎等价；Netgen 低插值权 **7.8×**、低体积比 **63×**、最大长宽比 11× 更差，慢 **13.5×**。
  （默认 vs 默认，未调参——不能读成引擎固有优劣；但「直接拿来用」场景下这就是决策依据。）

## 4. 三条病根（互相独立，均已定位）

1. **VMTK 表面重网格在这份高曲率/薄壁起伏曲面上本身产非流形边**（1.0 与 0.7 各坏一次）→ 这份几何上必须关重网格；「重网格调到目标尺寸」这条常规做法被否掉。
2. **边界层在壁面凹陷/缝隙自折叠**（已 `boundaryLayerOnCaps=False` 仍折叠）→ T-038 核心卖点「棱柱边界层」**至今未证实**。
3. **体积尺寸 > 表面尺寸 ⇒ 贴壁 sliver**（表面等效边长 0.569 mm vs 体积 1.0 mm）→ 方向性缓解（E），非根治。
