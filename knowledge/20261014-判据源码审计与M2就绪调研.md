## 一、T-001-A：`cellDeterminant` 判据源码审计

### 判决（L1）

**本地复算 `cellDeterminant` 不可作判据，一切以 `checkMesh -allGeometry -allTopology` 的 stdout 为准**
（min = 1.11163982652e-07，585 单元 <0.001）。

### 三个硬证据（L2）

1. **checkMesh 实际走的公式不在任务卡所说的位置**（任务卡写错了，已更正）：
   - `cellDeterminant` **不在** `primitiveMeshCheck.C`；库函数 `primitiveMeshTools::cellDeterminant`
     （`primitiveMeshTools.C:456`）也不是本次通路。
   - 真实调用链：`checkGeometry.C:865` → `polyMeshGeometry.C:2337` →
     `polyMeshGeometry.C:1989` 的 `polyMeshGeometry::checkCellDeterminant`。
   - 即 checkMesh 用的是**全面公式**（全部面），不是 `primitiveMeshTools` 的「仅内部面」公式。
2. **参考二进制是定制构建，源码无法 100% 确认公式**：
   日志文本 `(wellposedness)` / `minimum: X average: Y` /
   `***Cells with small determinant (< 0.001) found, number of cells: N`
   在整棵 v1912.200626 源码树中**搜不到**；源码同名例程打印的是
   `"Cell determinant (1 = uniform cube) : average = ...  min = ..."`（`polyMeshGeometry.C:2047`）。
   → 缺的是「那个构建的源码」，不是「本地脚本的算法」。
3. **`foam_repaired` 的 polyMesh 只存在于 WSL**，零 CPU 车道取不到数，
   无法跑修正脚本做实证（这是本卡的方法论限制，不是结论）。

### checkMesh 实际所用公式（`polyMeshGeometry.C:2014-2022`）

- 取单元**全部面**：`areaSum = Σ_i S_i·(S_i/|S_i|) = Σ_i |S_i|·(û_i û_iᵀ)`
- 分母 `magAreaSum = Σ_i |S_i|`
- `scaledDet = det(areaSum/(Σ|S_i|)) / 0.037037037037037`（×27，立方体归一到 1）
- 并矢 `ûûᵀ` 与面积矢量符号/朝向无关 → **owner-neighbour 归属、面节点顺序、翻转都不影响结果**

### 本地脚本差异根因（`outputs/T-001/scripts/reconstruct_determinant_from_polymesh.py:123-143`）

写错三处：① 面权重用 `|S|²` 而非 `|S|`；② 归一化用单个标量 mean/max 而非 `Σ|S_i|`；
③ 末项错用 `/8.0` 而非 `/0.037037…`。
→ 故 7.40e-08/575、1.16e-09/13441 都是**写错算法**的产物，对不上任一标准公式。

### `Failed 2 mesh checks` 的两项（日志 + 源码双侧确认）

1. **Cell determinant (wellposedness)** — 585 单元 <0.001（`checkMesh.log:102`；`checkGeometry.C:867`）
2. **Face interpolation weight (<0.05)** — **114 个面**（`checkMesh.log:106`；`checkGeometry.C:907`）

其余拓扑/几何检查全 OK。

### ⚠️ 对既有记录的更正（重要）

`state/状态.md` 的 A4 原写「本地判据复现不了 checkMesh → 不可作判据」，
**其理由是错的**：真实原因是**本地脚本算法写错三处**，不是「概念上不可复现」。
结论（以 checkMesh 为准）不变，但**理由必须更正**——否则下一轮会误以为
「本地永远做不出对应判据」，从而放弃一条本来可能走通的路。
**修正版公式至今未经实证**（零 CPU 车道取不到 WSL polyMesh）——这是明确的未决项，
不得反过来说「已证伪」。
