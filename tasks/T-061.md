## 合同要点

1. **建立单一真源 `workspace/pro/tokens.css`**：一处定义 ink/muted/faint/line/line2/soft/
   soft2/accent/warn/bad/bg/panel/canvas/mono；由 pro 外壳与各接入页 `link`，自包含单文件产物
   按同值内联并在样式头注明出处。
2. **chrome 一律单色**：外壳、标题、正文、边框、按钮、徽标、说明块靠**明度 + 字重 + 字形 +
   底纹**区分，不靠色相；状态词（VERIFIED / PARTIAL / BLOCKED / EXECUTING / OPEN / 未核）
   用不同的字重/斜体/下划线/底纹表达，**红黄蓝绿一律单色化**。
3. **颜色只留给数据本身**（tokens.css 纪律第 2 条）：三维几何分类色（壁面/鼻开口 L·R/出口帽/
   切除楔形/切面/标定标记状态）、流场速度·静压色带、图表数据系列，随各自图例就地声明，
   不进令牌表、不改动。
4. **尺寸语言统一**：圆角降为 2–3px、1px 描边、标签等宽 + 字距；圆角 >6px 视作旧版语言。
5. **正确性红线**：纯呈现层——**不动任何 CFD 数值 / 口径 / 患者结果**，不动几何资产、
   不动服务端契约；流线产物的**正文数据须逐字不变**（改色只碰 `<style>` 与绘图 chrome 字面量）。
