## 必须记录并回报的量（每个带出处）

1. **实际用的网格**：路径 + sha/尺寸 + 它的 checkMesh 三件套（cells / min determinor / `<0.001` 数 / 低权面数）。
   ⚠️ T-005 提醒：maxh=1.0 修复 → 预期 **114** 低权面；maxh=0.4 修复 → **106**。**先对齐，别混。**
2. **契约门结果**：`run_manifest.json` 里 `contract` 三件（`execution_allowed` / `forced` / `config_id`）。
3. **`engineering_acceptance` 回读**：必须是 `false`。
4. **收敛历史**：`log.simpleFoam` 里 residual 初值/终值（`Ux/Uy/Uz/p`）+ 是否达到 `controlDict` 的收敛判据；
   是否 `SIMPLE solution converged` 或 `FOAM FATAL`/`diverging`。
5. **压力**：入口（两鼻孔）与出口（nasopharynx_outlet）的**面积加权平均静压**，
   算出 **Δp（Pa）**，并**明确写出取压位置**（哪一面、什么平均方式、`foamPostProcess`/`postProcess -func` 的确切命令）。
6. **质量不平衡**：进出口流量差（应接近 0）。
7. **产物**：`foamToVTK` 输出的 VTK 目录路径（供 M3 可视化）。

## 判定（报告必须给明确结论）

- **收敛 + Δp ∈ [10,100] Pa** → 「网格虽不 `Mesh OK`，但**实测充分**」→ 建议 M1 收口，门禁待重定义。
- **收敛但 Δp 出带** → 不达标，报出实际值与可能原因（口径/边界/网格）。
- **发散/崩** → 报出**在哪一步、最后几步 residual、日志尾部原文**；并对照 585 差单元区/114 低权面区
  是否同步异常（T-005 的判读提示：把 `lowWeightFaces` set 放进 case 的 `constant/polyMesh/sets` 反查）。
