## 必做

### 1. 新增两个参数
- `--config <path>`：指向一份 config json（schema `nasal_cfd_config/v1`）。**可选**。
- `--force-unsanctioned`：`store_true`，显式确认「我知道这份配置未获授权，仍要跑」。

### 2. 行为（严格）
1. **给了 `--config`**：读 json → 调 `cfd_contract.validate_config(cfg)` →
   写入 `run_manifest['contract'] = {config_id, execution_allowed, errors, warnings, forced}`。
2. `execution_allowed is False` **且** 未给 `--force-unsanctioned`
   → **在任何 step 执行之前就拒绝**，非零退出，报错信息里**点名具体阻塞原因**（本场景原因在 `warnings` 里，
   如「solver adapter has not been implemented and verified…」「patient geometry requires human confirmed review」）。
3. **没给 `--config`** → **不拦截**（保持向后兼容），但写 `run_manifest['contract'] = {"config_id": None, "checked": False}`。
   ⚠️ **不给 `--config` 时的行为必须与今天逐字一致**（这是本卡最重要的兼容约束）。
4. 给了 `--force-unsanctioned` → `contract.forced = True`（**必须留痕**，可审计）。
5. **绝不**把 `engineering_acceptance` 置 True（`run_manifest` 里它还叠加 `force_unsanctioned` 时也不许放开）。

### 3. 导入契约模块
- 脚本在 WSL 下运行，`Path(__file__).resolve().parents[2] / "lib"` 即 `work/lib`。
- 按 `:45` 同款 `sys.path.insert` 模式导入 `cfd_contract`。
- **导入失败要给清晰报错**（说明缺哪个模块/路径），不要抛裸 `ImportError` 堆栈。

### 4. 测试（写进 `work/lib/test_run_openfoam_case.py`）
至少 4 项：
- (a) 不给 `--config` → 行为与改动前逐字一致（可用既有的 mock/命令序列断言）
- (b) 给 `--config` 且 `execution_allowed=false`、不给 force → **拒绝**且非零退出、报错点名阻塞原因
- (c) 同上但给 `--force-unsanctioned` → 放行，且 manifest 记 `contract.forced=true`
- (d) 给一份 `execution_allowed=true` 的合成 config → 放行，`contract.checked=true`（**用临时构造的 config，不要改 cataloge 里那 8 份**）

### 5. 跑全套测试
**不只跑你改的那两个文件** —— 跑 `work/lib/test_*.py` 全套，报 pass/fail 总数。
（项目纪律：改 `solver/**` 或 `lib/**` 必须跑全套，曾有「只跑定向测试漏掉别的 fixture」的事故。）
