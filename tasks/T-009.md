## 背景（为什么派这张卡）

契约 `work/lib/cfd_contract.py` 的 readiness 检查（L286-293）要求
`solver_adapter.status == "implemented_and_verified"` 才放行；`make_config()` 默认
`"not_implemented"`（L533-536）。这是 8 份配置 `execution_allowed=false` 的根因之一。
对 `total_flow` + `solver_determined` 分流，契约还要求
`desired_strategy == "common_inlet_pressure_feedback"` 且
`flow_target_role == "outer_iteration_objective_not_simultaneous_PDE_flow_boundary"`
——即「一个共同鼻孔静压 + 出口静压固定，外层循环调入口压力命中总流量目标；
不得同时施加流量边界」。

已验证原型已覆盖控制器算法，但**没有契约身份的适配器层**：谁能被 stamp、stamp 前自检什么、
stamp 后契约行为如何，全部未定义。本卡补这一层。**不跑真实求解**（医学门选 B 下
adapter 不阻塞矩阵；真实求解端到端留给 T-011 及以后的卡）。

## 任务（只做三件事）

1. **新建 `work/lib/solver_adapter.py`**：把 `pressure_feedback.solve_common_pressure`
   包装成契约语义的适配器。最低接口：
   - 构造参数来自 config：`inlet_patches` / `outlet_patches`（或 manifest 的 patch_map）、
     `target_m3_s`（由 total_flow_lpm 换算，注明 ρ 无关——流量是运动学量）、压力上下界；
   - `evaluate` 为**注入式回调**（签名 `(pressure_pa) -> FlowEvaluation`），代表「一次完整
     OpenFOAM 评估」。本卡只提供接口与一个合成响应适配器，**不实现真实求解调用**；
   - `run()` 返回：收敛压力、q_total/q_left/q_right/q_out、left_fraction、全程 iterations
     history、失败原因（`PressureFeedbackError` 原样上抛，不得吞）；
   - `stamp_config(config, name, version)`：**仅当自检通过**才把
     `solver_adapter.status` 置 `"implemented_and_verified"` 并写 name/version；
     自检至少包含：控制器算法自测（合成线性响应收敛到容差内）、符号门自测
     （反向流量被拒）、`flow_target_role` 与契约字符串逐位一致。自检不过 → 拒绝 stamp
     并抛出带原因的异常。**stamp 是显式动作，`make_config()` 默认值保持 not_implemented 不动。**
2. **新建 `work/lib/test_solver_adapter.py`**（unittest，项目既有方式，非 pytest）：
   - 合成响应：线性（q = k·p）收敛；非线性（q = k·p^0.9）仍收敛；容差边界；
   - 拒绝路径：入口符号为正 / 出口符号为负 / 非有限值 / 未收敛质量门 / 包围失败
     （压力到上界仍不到目标流量）/ 零流量；
   - 契约集成：未 stamp 的 `solver_determined` 配置 `validate_config` 仍报
     adapter not implemented（**防默认放行**）；stamp 后 readiness 清空；
     `desired_strategy` / `flow_target_role` / `strategy_description` 三个字符串逐位未变；
   - 四个屏值（0.005 / 0.005 / 1e-5 / 0.05）逐位未动的回归断言。
3. **接口文档**：在 `work/lib/solver_adapter.py` 模块 docstring 写清「本卡范围不含真实
   求解调用；接入 `run_openfoam_case.py` 属后续卡」，并在 `plan/主计划.md` Backlog
   登记「adapter 接入 prescribed 封装器」一项（一句话 + 理由）。
