# T-037 — 退化网格阳性对照（强化 H1：患者平台=网格缺陷）

**状态**：EXECUTING（2026-10-15 段主对话派发并亲自执行）
**依赖**：T-036（已 VERIFIED，提供阴性对照基线：干净圆管 p_floor≈1e-13）
**不依赖**：N6 / 患者几何 / T-012 裁定（决策无关，可独立推进）

## 目的（为什么做）

T-036 用"干净管 vs 患者 b15"做**阴性对照**：干净管（无 sliver/非正交）收敛到 1e-13，患者缺陷网格在 2.6e-4 不收敛 → H1 被"支持（强）"。但这是**缺失证据**（absence of reproduction），逻辑未闭环：还缺一个**阳性对照**——在干净管上**主动注入可控的近壁畸变**（模拟患者 b15 的 198 个严重非正交面 + sliver），看残差平台是否从 1e-13 回升到患者量级。若回升，H1 从"支持"升级为"正向证伪（成立）"；若不回升，须修正 H1（可能另有成因）。

## 方法（已核验可行性）

- 复用 `phantom_validation.generate_tube_stl` 的几何（L=40mm/D=4mm、Re≈5275，同 T-036）。
- **注入畸变**：在圆柱壁面叠加径向正弦扰动 `r(z,θ)=R + amp·sin(kz·2π·z/L)·sin(kθ·θ)`，振幅 `amp` 取三档（0.05 / 0.15 / 0.30 mm，相对 R=2mm 即 2.5% / 7.5% / 15%），inlet/outlet 圆盘同步按 r(0,θ)/r(L,θ) 收口保持水密。
- 网格：0.4mm、refine "0 0"（与 T-036 干净管同构基底），保证差异**只来自壁面畸变**而非网格拓扑本身。
- 求解预设：**t006**（= 患者 b15 同设置，单一变量，排除 H3/H4 干扰）。
- 全链：`surface_to_case → run_openfoam_case(块/snappy/checkMesh/simpleFoam/foamToVTK)`。

## 验收标准（可观测）

1. 三档退化管 `checkMesh` 的 **maxNonOrthogonality** 与 **sliver/非正交面计数** 均显著高于干净管（干净管 0 sliver、maxNonOrth 低）；否则实验无效（畸变未传导到网格）。
2. 三档退化管 `p_floor` 出现**梯度式回升**（随 amp 增大而升高），且至少最高档逼近/进入患者量级（~1e-4–1e-3 量级）⇒ H1 阳性对照成立。
3. 若最高档仍远低于患者 2.6e-4，则诚实记录"可控近壁畸变不足以复现患者平台，H1 维持'支持'而非'证伪'"，并将"需注入真实 sliver（如患者网格直接移植）"列为后续待办。
4. 全程不改共享代码（`surface_to_case.py`/`run_openfoam_case.py` 等）；只新增 `work/lib/phantom_matrix.py` 的 degrade 模式 + 写 `outputs/T-037/`。
