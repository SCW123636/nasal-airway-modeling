## 0. 委托方上下文（脱敏；执行本题必需的背景）

**我们在做什么**：我们有 24 例鼻腔/鼻窦 CT 的 CFD 后处理指标——鼻阻力、壁面剪切应力（WSS）、黏膜热通量、后鼻孔温湿度、各鼻道气流占比。**没有逐例症状评分，没有健康对照组**。

**当前设计（S4 路线）**：症状标签永远拿不到，所以不做「预测症状的模型」，改为：① 把 24 例按 CFD 特征做无监督聚类分表型；② 把每个表型对应到文献已发表的气流表型（如 Park 2025 的中鼻道优势/下鼻道优势/混合型）；③ 转译该表型在文献中报告的症状关联。**症状陈述全部是文献迁移，本队列零验证——这是假说生成，不是验证研究。**

**已完成的相关调研结论（本题的背景，不必重查）**：
- CFD 全局指标（总阻力/总压降）与症状评分弱相关或阴性；金标准器械也如此（鼻测压 NAR 与症状 r≈0.1–0.4）
- 区域/感觉相关量与症状中等至强相关：下鼻道峰值 WSS（n=27, ENS6Q r=−0.398）、黏膜热通量 SAHF50（n=10, NOSE r=−0.76）、中鼻道气流占比（n=30, |r|=0.76）、鼻腔前端温降（R²=0.62）
- 文献表型的定义方式五花八门：Park 2025 的气流分型是**冠状面速度分布的目视定性判读**；其鼻阻力定义为 Δp÷流量（Pa·s/mL）双侧合并；其 CFD 用 250 mL/s、入口 25°C/35%RH 稳态吸气

**本题的两个缺口**：
- **题5**：我们的聚类稳定性门槛（ARI/Jaccard ≥ 0.75）是经验值，n=24 的聚类本身可能不稳——需要小样本聚类的稳定性协议与门槛裁定
- **题6**：我们的「指标对应/表型对应」方法（不同研究的测量截面、归一化、物理边界条件不一致时怎么对齐；把文献表型定义套到新队列怎么检验效度）需要领域成熟做法

## 1. 题5：小样本无监督聚类的稳定性协议与门槛先例

**背景**：24 例、4 个连续特征、计划 PCA 降维后 k-means 聚类，k 由轮廓系数 + bootstrap 稳定性共同裁定。稳定性门槛暂定 ARI/Jaccard ≥ 0.75，但该数字缺乏出处。若稳定性不达标，降级为「连续特征百分位报告」（不硬分类）。

**请逐条回答**（每条给出处：作者/年份/期刊/DOI 或 PMCID/n）：

- **Q5.1** 医学/影像/生物信息/组学领域，报告聚类稳定性的常用指标（ARI、Jaccard、FM 指数等）及**常用裁定门槛值**——如 Jaccard≥0.75 或 ARI 接近 1 这类门槛的文献出处与适用条件是什么？不同领域（如共识聚类 consensus clustering）的门槛是否不同？
- **Q5.2** bootstrap 聚类稳定性的**标准协议**：重采样次数（100？500？1000？）、稳定性的计算方式（簇间 pairwise co-occurrence 平均 / 每簇 Jaccard 的加权）、报告的规范格式有无先例？
- **Q5.3** 小样本下 **k 的选择**：轮廓系数 + 稳定性联合使用的先例？有没有「每簇最少样本数」或 n/k 比值的经验下限（如 n/k ≥ 10）？k 的上限怎么定？
- **Q5.4** n<30 医学队列做无监督表型/亚组分型的**已发表先例**（任何领域：重症/肿瘤/罕见病/呼吸/影像组学）：样本量怎么论证充分性、稳定性怎么报、有没有审稿人要求的先例？
- **Q5.5** 聚类稳定性**不达标时的标准处理**：改用潜类别分析（LCA）/混合模型、半监督方法、或明确降级为连续特征描述——各自的先例与取舍？
- **Q5.6** 鼻腔/上气道 CFD 领域，除 Park 2025 的目视分型之外，有没有**基于 CFD 指标的聚类/表型分型研究**（任何样本量）？

**建议检索词**（中英文）：clustering stability ARI Jaccard threshold small sample / bootstrap cluster stability medical subtyping / consensus clustering stability small cohort / latent class analysis small sample phenotyping / unsupervised subtyping small cohort / 聚类 稳定性 小样本 分型 / 表型 分型 稳定性 门槛。

## 2. 题6：跨研究指标协调与外部表型迁移

**背景**：文献的 CFD 指标定义各不相同（测量截面、归一化方式、物理边界条件、单侧/双侧），我们要把文献指标映射到自己的特征空间；还要把文献表型定义套到自己队列。需要知道这个领域「指标对齐」和「外部定义迁移」的成熟做法与公认禁区。

**请逐条回答**（每条给出处）：

- **Q6.1** 跨研究**指标定义不一致**（截面/归一化/单位/物理条件）时的对齐方法学：影像组学的特征协调（feature harmonization、ComBat 等）解决的是什么问题、**能不能用于「异指标映射」场景**（不同研究测的根本不是同一个量）？指标报告规范（TRIPOD、放射组学质量评分 RQS、STARD）对「可比性」的明确条款有哪些？
- **Q6.2** 把**已发表表型分类标准应用到新队列**的效度怎么检验：标注者间一致性？与独立维度交叉验证？前瞻性确认？请给先例（如 WHO/分子分型标准应用到新队列的方法学论文）。
- **Q6.3** 不同 n/人群/设计的效应量（r 值）如何做证据合成：叙述性合成（narrative synthesis） vs 正式 meta 分析的条件；证据分级（GRADE / 牛津 OCEBM）在「方法学清单」场景怎么用。
- **Q6.4** 文献阈值/模型**迁移到新数据**的公认禁区与最低验证要求：TRIPOD 的「外部验证」条款具体要求；把别的 BC 下测得的阈值（如某研究的 WSS 阈值 Pa 值）直接套到不同 BC 的新数据，为什么不被接受——给出方法学出处。

**建议检索词**（中英文）：feature harmonization multi-study radiomics / ComBat cross-study batch effect limitations / metric alignment cross-study comparability / external validation published phenotype criteria new cohort / evidence synthesis heterogeneous correlations narrative GRADE / transporting prediction model threshold external validation TRIPOD / 影像组学 多中心 特征协调 / 表型 标准 迁移 新队列 验证。
