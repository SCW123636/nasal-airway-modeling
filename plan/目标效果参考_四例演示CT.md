## 软件链路判读（用户补充后核对）

项目已有的录屏分析记录了对方实际采用的处理链路：

1. **3D Slicer**：导入 DICOM，按空气 HU 阈值分割，再在鼻孔等位置手工切断外部空气连接，检查并导出气道 STL。录屏参数记录为 3D Slicer 5.10.0、`-3024 ~ -400 HU`；这是人工参考流程，不是当前自动管线的固定阈值契约。
2. **Blender**：对 STL 做减面、去重、法向一致、填洞和网格检查。录屏记录为 Blender 4.2；本机已验证的替代环境为 Blender 5.2.2 LTS。
3. **SimScale**：把气道表面与进出口圆柱合成为空气计算域，设置不可压缩流体、边界条件、网格和求解；录屏记录为 `0 Pa` 总压入口、`18 Pa` 表压出口、稳态 SIMPLE / k-omega SST。
4. **后处理**：在 SimScale 中查看速度、压力、湍流等场。项目本地记录同时验证了 3D Slicer 内置 VTK 可作为 ParaView 后处理替代，但这不表示四例目录中已有 CFD 场结果。

因此要复现的是“**Slicer 分割与人工开口 → Blender 修复 → SimScale/OpenFOAM 求解 → 三维场显示**”这条软件流程及其显示结果。四例目录里的 `MPR`、`3D_Sinus`、`CH/CH_4` 是 CT 扫描/工作站导出的二维重建或定位截图，属于输入和影像参考，不能当成该软件链路已经输出的 STL 或 CFD 场。

版本差异必须单独记录：录屏是 Slicer 5.10.0 / Blender 4.2；本地实测是 Slicer 5.12.4 / Blender 5.2.2，SimScale 仍需凭证或改用本地 OpenFOAM。复现验收应比较操作步骤、切面/开口、几何单位、边界条件和速度/压力/湍流显示，不能只比较截图外观。
