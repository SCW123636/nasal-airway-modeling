# 需求方待决项（M3 外部阻塞清单）

> 2026-10-14 由段主对话整理。M3 矩阵 Phase A（例0，无 PHI）不依赖以下任何一项；但 **T-012（Phase B/C/D + K2 量化对照报告）被这些项阻塞**。矩阵三档全跑作灵敏度，**对外基准值需需求方定一档**。
> 本清单只登记「必须由需求方/复核方裁定」的口径与标准；工程侧能做的（矩阵、证据链、透明标注）已在跑。

## 1. 阈值基准裁定（−300 / −350 / −400）

- **现状**：SOP 主口径 −300（与试点管线一致）；−350/−400 是外部主张，未经裁定。
- **为什么卡**：K2 量化对照报告与一切对外基准值都要有一个法定阈值；三档并报会给不出单一结论。
- **矩阵 interim 做法**：三档全跑（T-011 Phase A 的阈值轴），产 Δp 对阈值的灵敏度——把「选哪档」变成有数据支撑的决定。
- **需要的裁定**：对外基准阈值取哪一档（或明确「分场景双轨」）。

## 2. 出口边界条件口径（0 Pa vs 18 Pa）

- **现状**：矩阵与全部实证（T-004/T-006）用出口 0 Pa；外部材料出现过 18 Pa。
- **已核验事实**：18 Pa 是 SimScale 的**出口端 gauge 静压、不是 Δp**——两者不是同一个量，不能互换（`外部调研核验结论_20261012.md` 采纳口径）。
- **为什么卡**：Δp 判据带（10–100 Pa）的解释依赖出口基准；若出口改 gauge 静压，全部 Δp 数值的系统偏移量需重算。
- **需要的裁定**：出口边界条件采用哪一口径（建议维持 0 Pa 直至 18 Pa 的原始作者确认其定义）。

## 3. K2 人工金标准（自动分割 vs 人工的对照判定）

- **现状**：K2「自动分割与人工金标准在解剖边界/进出口/连通性上一致」是五大验收标准之一，目前阻塞——自动管线只保证**开口面积入带**（N6），位置正确性只能由复核确认（`正常路径基本方法_v1.md` §4）。
- **已有基础**：王湧瑞 2026-10-07 五例 ×5 点位 25/25 accept（开口定位 v2 的 reviewed 锚点即来源于此）。
- **为什么卡**：没有金标准判据，「量化对照」四个字无法落地——不知道拿什么比、怎么算一致。
- **需要的裁定**：金标准形态（逐点位坐标？边界距离场？连通性布尔？）与合格阈值。
