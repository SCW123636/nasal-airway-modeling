> 本文只回答一个问题：**怎样让「标准模型」的每个数字、每条判据、每句陈述都有依据**。模型选什么算法是上游文档的事；依据怎么长出来，是本文的事。

## 0. 结论先行

**「有依据」不是态度，是一组可检验的工程判据。** 本标准模型的依据架构 = **四层证据（E0–E3）× 三类声明（C-a/C-b/C-c）× 三个部件（S1/S3/S4）**，外加一条第一冻结对象：**口径维度**。

三条核心判断：

1. **第一障碍不是算法，是口径。** T-058 三例实测证明：同一条几何，切割口径从轴位改成解剖斜切，b15 的 Δp 从 18.267 → 17.12 Pa（−6.3%）、出口面积 +12.8%。而我们队列内部**同时存在两套 BC**（50:50 固定分流 vs 共同静压自然分流，T-058 三例跑在前者上，患者全链在后者下只有参考例）。在自己队列里跨口径混算 = 在文献桥接里跨 BC 对标（设计文档 §13.4 已禁）——**同一个错误的两倍版本**。所以标准模型动工第一刀是口径冻结与口径标签，不是聚类。
2. **claim 必须分级且句子模板化。** 标准模型的输出只有三种合法句子：队列事实（C-a）、锚点偏离（C-b）、文献迁移假说（C-c）。每份报告的每句话归属某一级、带登记表 ID。这是防「摘樱桃式表述」的语言层落地，也是本项目 7 次「判据合法但与事实不符」事故的根治方向之一。
3. **已知答案验证从纪律升级为 CI。** 每个特征提取器/判据必须先在一个带出处的已知答案上逐位通过，才准碰队列数据。现成夹具已在手：T-054（b15 轴位基线）、T-047（b01）、T-058 三例汇总裁决（b02 新基线）、T-043 Graetz 合成验证（温度/热通量提取器）。

## 3. 口径维度：标准模型的第一冻结对象

### 3.1 为什么是第一障碍（T-058 实测证据）

| 口径维度 | 现状 | 实测影响 |
|---|---|---|
| **域** | 扩展域（鼻+鼻咽+可见口咽，choana 为域内截面） | 03:3x 已统一，b15/b01/b02 对齐 |
| **切割** | 轴位（⊥扫描 z，T-054/T-047 基线）**vs** 解剖斜切（⊥局部气道轴，T-058 现行） | b15：Δp −6.3%、R −6.3%、出口面积 +12.8%、WSS 力 −1.4%；差异**预期且非回归**（出口几何变了），但跨切割口径混算即失真 |
| **BC** | 50:50 固定分流+出口 0 Pa（T-006/041/042/047/054/058 全患者链）**vs** 共同静压自然分流（T-021/T-029，仅参考例+合成） | 患者全链 X 侧今天**只存在于 50:50**；T-058 metrics JSON 明写「comparable ONLY with …NOT with T-021/T-029」 |
| **阈值** | −300 主（−400 探跑留了第一个灵敏度点） | b15 气域 −8.3%，水密如常；需求方待决 #1 |
| **数值模板** | S-A 600 步，medium-to-fine ≤5% 屏（T-007 约束） | 三例全部 `converged:false`（Ux 残差 9.4e-5/4.4e-5/1.7e-3）、`unchecked` |

**b02 的警示**：同口径下 b02 的 R=0.173 Pa·s/mL 是 b15（0.068）的 2.5 倍、WSS max 22.9 Pa 是 b15（3.5）的 6.6 倍——队列异质性是真实的，常模必须能描述它；同时提示 QC/分层（层厚/设备/诊断构成）不是装饰。

### 3.2 口径纪律（标准模型侧规则）

1. **每个特征值带口径标签**（域/切割/BC/阈值/数值模板/收敛状态六元组），特征表 schema 的一等字段，不是脚注。
2. **常模按单一口径建**；跨口径只做「口径差异并列展示」（如 T-058 对 T-054 的 reconciliation 段做法），不做混合统计。
3. **D-0（BC 选型）重新提级为第一冻结项**（上游 §11 曾因「配对相对变化为主口径」将其降权——该逻辑只覆盖 S4 症状映射，**不覆盖 S1 绝对百分位常模**）。建议路线：标准模型先按**现成可得的 50:50 链**建（T-058 已验证、与全部历史基线可比），D-0 作为**版本化切换点**预留——裁定共同静压后「重算+版本+1+新旧并列」，不混算、不重训（沿用上游参数化原则）。
4. **切割口径已实质切换为解剖斜切**（T-058 提交链），对账基准随之更新：b15/b01 与 T-054/T-047 的差是口径差不是回归差，鼻孔侧回归（80.04/80.06、80.08/80.08、80.15/80.22 三例全 match）才是回归检查。**特征表的已知答案夹具必须同步刷新为 T-058 汇总裁决值**，否则 CI 会拿旧口径当真理。

## 4. 三类声明与句子模板（C-a/C-b/c）

标准模型输出的每句话，必须能归入以下一级；归不进的句子不许出现。

| 级 | 模板 | 例 | 依据层 |
|---|---|---|---|
| **C-a 队列事实** | 「我们的 n 例（有效 n=X，指纹/口径六元组见特征表）该特征分布为 median=IQR=…」 | 「24 例（有效 21）Δp@250 队列 median 22.4 Pa / IQR 17.1–29.8」 | E0 |
| **C-b 锚点偏离** | 「该例/该簇该指标为 V，对文献健康锚点 A（n=…, BC 声明）偏离 d——**不作正常/异常判定**」 | 「b02 后鼻孔 T=31.8℃，低于文献健康锚点 32.2℃（n=5）」 | E0+E1 |
| **C-c 文献迁移假说** | 「该簇在 [文献]（n=…, [效应量]）中对应 [方向] 症状倾向——**文献迁移，未在本队列验证**」 | 「低 WSS 簇在 Li 2018（n=27, r=−0.398）中对应更高 ENS6Q 方向」 | E0+E2+E3 |

**禁句**（写进每份报告头）：「该患者 ENS6Q≈X 分」「该型会导致 Y 症状」「正常/异常」「该值高于文献阈值故异常」（数值迁移禁令）。

## 5. 逐部件依据设计

### 5.1 S1 队列常模（主产品的解释层）

- **输入**：单一口径（当前=50:50+斜切+扩展域+−300）冻结特征表；QC 门（层厚 ≤0.6 mm、分割水密/开口 auto_pass、网格门记录项）后**有效 n 逐特征报**，不按名义 n。
- **统计**：逐特征 median/IQR/分位数 + 采集元数据分层（层厚/设备）；b02 类离群先查口径再谈分布。
- **锚点层**：E1 常量单独一列，永不并入队列估计。
- **已知答案验证（B2 落地）**：常模表生成后，b15 的 Δp/R/WSS 三列必须与 T-058 汇总裁决值逐位一致（17.12/0.0685/1.485e-3 N），b01 对 T-047 的并列口径差按 §3.2-4 处理。不一致 = 提取器或表装配有 bug，停下。
- **输出**：每例每特征三列 = 队列百分位 ｜ 锚点偏离（C-b 句式）｜ 口径六元组 + clinical_status + 收敛状态。
- **claim 边界**：只报百分位与偏差；绝对值不对标临床鼻测压（C4）；跨例比较只用同协议相对量。
- **降级**：QC 门刷掉的例 → 降级「仅形态学」并记账；聚类稳定性失败时 S1 自身不受影响（它本就不分类）。

### 5.2 S3 解剖形状常模 SSM（几何，可最早开工）

- **输入口径修正**：上游 §6 写「24 例气道 mesh 现在就能做」——写在域标准统一之前。按 §3.2，**S3 输入必须与 Stage 0 同域（扩展域）**；现存 24 例表面是短域旧产。正确起步 = 24 例扩展域**表面**重跑（stage 3，marching cubes，轻 CPU，不含网格求解），跑完再 PCA。这不是阻塞，是把「零成本现在就能做」修正为「轻成本、需一次批量」。
- **方法**：点对应建立（**选型属前置设点、执行前请人类裁定**：模板+非刚性配准 vs 无对应方法）→ PCA → 下鼻道变异主成分 + 通用型覆盖率（覆盖率定义预注册：累计方差阈值 + 模态数）。
- **依据判据**：领域标准三指标——紧凑性 / 通用性 / 特异性（Stymer 类先例）；留一例重建误差报泛化；24 例建模范的样本量局限如实写进报告（n=24 的 SSM 是「本队列几何描述」不是「人群解剖常模」）。
- **claim 边界**：只描述本队列几何分布；「通用型覆盖率」是工程/器械设计语言，不引申为解剖学结论。
- **价值定位**：下鼻道解剖变异人群数据是文献点名的领域空白（患者需求索引），产出即贡献；同时是 S4 表型分层的防稀释维度（交叉备用）。

### 5.3 S4 表型聚类 + 文献症状映射（症状对应主线，假说生成）

- **X 侧预注册**（看数前冻结）：四主特征 = 黏膜热通量 SAHF50（>50W/m² 面积占比）/ 下鼻道峰值 WSS / 中鼻道气流占比 / 前端温降 ΔT；全局 R 与 WSS 力仅客观读数不进聚类（C5 裁定 + 题1 四方证据）。特征 schema 版本化。
- **聚类**：标准化（队列内 fit）→ PCA 保留 ≥80% 方差 → k-means/层次；k 由轮廓系数 + bootstrap 稳定性（ARI/Jaccard 门槛待题5 回收裁定，暂 0.75）共同定；**稳定性不过的 k 不进入报告**。
- **命名-映射分离**（防循环论证）：命名链只用描述性/结构文献且在看症状数据前冻结；映射链只用关联性文献；操作化阈值判据标 E3/B 级，五篇原文细节复核（题6 附）不过的映射撤下。
- **映射层**：只转译方向与显著性状态（L3 规则）；每条陈述带登记表 ID + 多源标注（≥2 独立源=多源支持，单源=探索性）；反例（Park 2025 阴性、NAR 弱相关）必进附录。
- **输出**：排序假说清单（按 多源状态 × 证据等级 × 效应量 排序）+ 每例剖面卡（簇标签含稳定性数值 / C-c 句式症状解释 / S1 百分位 / 锚点偏离）。
- **可失败性（预注册）**：① 全部 k 稳定性 <门槛 → 降级为 S1 百分位报告（宁可不分类）；② 表型与 S3 几何/客观量系统性矛盾无解释 → 映射层可信度崩塌，回退重设计；③ 映射文献复核不过 → 该条撤下；④ 将来新病例落簇率 <80% → S4 关闭。

## 9. 诚实边界（本标准模型永不声称）

1. 不产出「正常/异常」个体判定（归复核人口径，本模型只报百分位与偏差）。
2. 不产出个体症状预测数字（S2 已永久关闭；S4 只做方向性群体层面假说）。
3. 绝对值不跨 BC/切割口径对标文献（§13.4 数值迁移禁令，对自己队列同样生效）。
4. 队列均值 ≠ 正常（无健康对照；正常只能来自 E1 锚点）。
5. n=24（有效 n 可能 <24）的分布是「队列描述」不是「人群常模」；SSM 同理。
