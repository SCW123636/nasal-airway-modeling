## 4. 四个选项（协作协议四选一）

### 选项 A：微调（推荐）—— M1 按「实测充分」收口，出口条件改双轨

- M1 出口改为：**主判据 = 求解收敛 + Δp 入 10–100 Pa 带 + 质量不平衡 ≤ 1e-4（相对）**；
  `checkMesh Mesh OK` 降为**记录项与精度风险提示**（对外材料**不得**宣称 Mesh OK）。

  （如 <45° 用 0 / 45–75° 用 1–2 / >75° 用 2–3，附本项目实证依据），
  并给 `surface_to_case.py` / 模板生成处加「按 nonOrthogonality 自动选档」的逻辑。
