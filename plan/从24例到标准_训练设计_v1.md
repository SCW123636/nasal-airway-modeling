# 从 24 例到「标准」：训练设计 v1

> 2026-10-16 · 段主对话 · **只设计，未执行**
> 承接用户提问「怎么通过二十多例训练出一个标准」；三轮患者需求调研已建立症状↔气流/黏膜湿温的对应关系。
> 关联：`knowledge/患者需求/`（三轮调研 + 需求转译）、`plan/需求方待决项_M3.md`、T-058（扩展域标准）、T-054/T-047（扩展域基线）、`research/20261015-症状与局部气流近期研究核对.md`。

## 0. 结论先行

「训练出一个标准」在本项目 = **三个不同的东西，只有两个现在训得动**：

| # | 「标准」 | 本质 | 现在能训吗 | 卡点 |
|---|---|---|---|---|
| **S1** | 队列常模参考框架 | 描述统计 + 文献锚点 | ✅ 输入标准化之后 | T-058 收卡（24 例重跑） |
| **S2** | 症状预测模型 | 监督学习 | ⛔ 训不了 | 逐例症状标签 = **0 例** |
| **S3** | 解剖形状常模（SSM） | 几何 PCA | ✅ 现在就能 | 无（纯几何，零 CFD） |

**一句话**：文献给「标准」（锚点与关系），24 例给「分布与偏离」。不是从 24 例患者训出一个「正常」，而是把文献锚点校准成队列常模；新患者进来 → 同协议提特征 → 输出「队列百分位 + 文献锚点偏差」剖面。症状预测要等标签，且 n≈24 只能上预注册小特征 + 强正则。

## 1. 三个硬现实（设计前提，不可绕）

**R1 没有标签。** 24 例副鼻窦 CT（b01–b24）无任何逐例症状评分；ENS6Q / SNOT / NOSE 只存在于调研文献（ENS6Q 六条目、MCID=7、截断 ≥11 均为外部值）。B 数据集的「2449 帧」是 **DICOM CT 帧数**（3 患者 1.1 GB），不是症状时间序列。→ 监督学习今天没有 y。

**R2 没有健康对照。** 队列 = 副鼻窦患者 CT；A 底座（0.35 mm）是链路验证例，健康状态未核验。→ 「正常」不能由队列均值定义；正常只能来自文献锚点（健康 n=5：32.2±0.2 ℃ / 93.5±1.5 %RH）。

**R3 输入未冻结。** T-058 只完成 3 例（b15/b01/b02）新域标准对账，其余 21 例表面未重跑、24 例网格+求解未重跑；历史上存在两套 BC 口径（50:50 vs 共同静压）与短/扩展域混杂。→ 混合输入上训练任何东西都违反项目自己的输入冻结协议。

**附带：采集混杂。** 24 例来自不同医院/设备，层厚 0.35–1.0 mm、重建核与 RescaleIntercept 不一（B 数据集已实证两种截距混用）。文献影像红线 ≤0.6 mm 各向同性 → **QC 门后有效 n 可能 < 24**，统计按有效 n 做，不按名义 n。

## 2. Stage 0：输入冻结（任何「训练」的前置门，不是训练本身）

| 项 | 冻结内容 |
|---|---|

| 几何 | 24 例表面+开口重跑（C1–C6 判据）→ 网格+求解重跑（另立卡，CPU 独占串行） |

## 3. Stage 1：特征层（解剖驱动预注册，禁数据挖掘）

特征清单在看见任何结局之前冻结（防 cherry-pick）。每特征带出处与证据权重：

**几何特征（Stage 0.5 即可全量算，零 CFD）**：最小截面积 MCA 及位置、鼻阀面积、气道容积、黏膜面积、左右容积比、下鼻甲残存度量、中/下鼻道容积比、后鼻孔面积、采集元数据。

**CFD 特征（Stage 0 后）**：R（仅配对口径）、Δp@250 mL/s、WSS 分布（median/p95/高剪面积占比）、**下鼻道 WSS 占比**（ENS 32.2%±12.5% vs 正常/术后 46.5–54.0%，与 ENS6Q 相关）、**热通量 >50 W/m² 黏膜面积占比**（与 NOSE/VAS 相关性最强）、**后鼻孔 T/RH**（对标 32.2 ℃ / 93.5 %RH）、SAVR（n=14 中 RH 唯一相关参数）、左右分流、中鼻道射流占比（棉花试验 −41% 为干预靶）。

**证据分级（进模型时的先验权重）**：
- 强（L1 多源）：后鼻孔 T/RH、热通量面积占比、下鼻道 WSS 占比、MCA
- 中：R（配对）、SAVR、左右不对称
- 探索：全局 WSS、射流占比
- **C5 硬规则**：n=14 研究无全局 CFD 参数与 ENS6Q 相关 → 全局 R 只作「矛盾性鼻塞」客观读数，**不得作为症状相关主特征**（D1 裁定前）。

## 4. S1 队列常模（主产品，输入冻结后可交付）

- **算法**：24 例（有效 n）特征表 → 逐特征 median/IQR/分位数；采集元数据分层（层厚/设备）。
- **文献锚点层**（外部常量，不带入队列估计）：健康 32.2±0.2 ℃ / 93.5±1.5 %RH（n=5）；ENS 31.4±0.9 ℃ / 84.6±7.7 %RH（n=14）；下鼻道 WSS 占比 46.5–54.0%；热通量 >50 W/m² 相关（PMC12791179）；MCA 临床鼻测压带；棉花栓先验（位置 1.74±0.26 cm / 长度 1.93±0.35 cm）。
- **输出 = 患者功能剖面**（每特征三列）：队列百分位 ｜ 文献锚点偏差 ｜ 口径与 `clinical_status: generalisation_test_only_no_human_review` 声明。
- **接入协议**：新患者 CT → 同 protocol（同域/同 BC/同网格档）提特征 → 剖面对比。这就是「标准」的日常用法。
- **边界**：常模是「队列分布」不是「正常」；只报百分位与偏差，**正常/异常判定不做**（归复核人）；绝对值不可对标临床鼻测压（C4），跨例比较用同协议相对量。

## 5. S2 症状预测模型（标签到位后才训；现在 0 例）

- **标签来源路径**：① IIT/RCT 入组（ENS6Q 前后，MCID=7，交叉设计 n≈8–12）；② B 患者3 双时间点 CT（2025-07-09 / 2026-02-17）——唯一的潜在配对；③ 未来门诊自评采集。
- **训法（n≈24 量级，二选一或并行）**：
  - a) 预注册 ≤5 个强证据特征 + 岭回归/弹性网；LOO-CV + 置换检验 + bootstrap CI；报效应量不追 p。
  - b) 贝叶斯分层：先验取文献（相关方向与强度，如 RH↔SAVR、热通量↔NOSE/VAS），队列似然更新——小样本下比频率派回归稳。
- **验收判据**：LOO R²/RMSE 带 bootstrap CI；置换检验 p；bootstrap 特征入选率；不过 LOO 不报数。
- **禁令**：深度学习（24 例）；数据挖掘式特征选择；全局 R 主特征；把队列均值当「正常」；任何输出不带 clinical_status。

## 6. S3 解剖形状常模 SSM（并行，现在就能做）

24 例（+3 患者）气道 mesh → PCA → 下鼻道变异主成分 + 「通用型覆盖率」。这是调研报告自己点的 P1 动作与领域空白（R7），零 CFD 成本，可直接支撑器械设计空间与「层厚—精度对照」空白研究。可与 Stage 0 并行（零 CPU 车道）。

## 11. 用途裁定：症状对应为主线目标（2026-10-16 用户拍板）

**裁定记录**：用户 2026-10-16 08:1x 定——「目前用途放在症状对应，我认为这个是后面所有的前提」。

**裁定的含义（对既有结构的调整）**：
1. **S2 升格为主线目标**：从「挂起等标签的分支」变为整个「标准」的目标函数；「症状对应」取宽定义——CFD 指标与症状评分的映射，含关联强度、代理指标、表型分层解释，不限于预测模型（n≈24 规模即便有标签，更可能产出「关联/代理」而非「预测」，见调研 S2 判据）。
2. **S1 队列常模 / S3 几何 SSM 降格为支撑模块**：S3 的表型分层是症状对应的防稀释手段（调研实证：混合表型入组稀释关联）；S1 的分布与偏离是症状对应的解释层与协变量来源。
3. **两条前提链**（「前提」的准确拆解）：
   - 工程前提 = **输入冻结（Stage 0，T-058 收卡）**——症状对应的 X 侧特征必须来自冻结输入，否则一切白算；
   - 数据前提 = **症状标签（Y 侧）**——24 例无逐例评分（已核实），当前 X 侧可全速推进，Y 侧只能靠病历挖掘或采集。

**症状对应路线图**：

| 阶段 | 内容 | 状态 |
|---|---|---|
| A（X 侧，现在可全速） | 输入冻结 + 四主特征预注册（热通量 SAHF50/下鼻道峰值 WSS/中鼻道气流占比/前端温降，R 作客观读数）+ 24 例特征表 + S3 表型分层维度 | 等 T-058 收卡即启动 |
| B（Y 侧，标签） | ① 病历挖掘（电子病历鼻塞主诉/术后史/随访记录——先证明「确实没有」再走采集）；② 采集按 S2 最低可行设计（≥28–30 例/NOSE+ENS6Q/3 月随访/单侧提取/表型分层）；③ B 患者3 双时间点 CT 作配对探针（n=3，仅验证「变化量对应」可行性） | 待用户拍标签来源 |
| C（模型） | 标签到位后按 S2 判据执行：≤1–2 特征未正则化或 LASSO、重复分层 k 折+嵌套 CV+bootstrap .632+、95%CI+校准必报、文献先验贝叶斯默认路线 | 阻塞于 B |

**对剩余岔路的影响**：②（标签）升为最高优先级——它是症状对应的数据前提，建议先做病历挖掘（零成本）再定采集；④（BC 口径）权重下降——症状对应以配对相对变化为主口径，BC 只影响 R 绝对值报法；③（健康对照）继续服务于 S1 解释层。

### 12.2 S4 设计：无标签条件下唯一站得住的症状对应路径

核心逻辑：**不预测症状，而把每例患者归入文献已描述的功能表型，再转译该表型已发表的症状关联**。症状陈述全部来自文献迁移，本队列零验证。

**输入（X 侧，全部来自冻结输入，等 T-058 收卡）**：
- 四主特征：黏膜热通量 SAHF50（>50W/m² 面积占比）、下鼻道峰值 WSS、中鼻道气流占比、鼻腔前端温降 ΔT
- 全局读数（仅客观报告，不进聚类）：R、WSS 力
- S3 几何表型维度（下鼻道/中鼻道横断面积谱）交叉备用

**方法链（n=24 小样本，全部判据预注册）**：
1. 特征标准化（训练队列内 fit）
2. 降维：PCA 保留 ≥80% 方差的主成分（预期 2–3 个）
3. 聚类：k-means/层次聚类，k 由轮廓系数 + **bootstrap 稳定性（ARI/Jaccard≥0.75 才接受该 k）**共同裁定——小样本聚类不稳定是已知风险，稳定性不过的 k 不进入报告
4. 表型命名：对照文献表型学描述（Park 2025 的 MT/IT/Mixed 气流分型与下鼻道优势表型、ENS 腔体过大表型、MCA 狭窄表型），只命名有文献依据的簇；无法对应的簇如实报告「未匹配表型」
5. 症状映射层：每簇按文献报告的方向与量级转写症状倾向陈述（例：下鼻道峰值 WSS 低的簇 → Li 2018 ENS6Q 负相关 r=-0.398 方向 → 「该表型在文献中对应更高空鼻症症状评分方向」），**每条陈述必须带来源 + 证据等级**

**输出形态（替代原 S2 的每例剖面卡）**：
- 表型标签（含 bootstrap 稳定性数值）

## 13. S4 桥接协议与科学性评估（2026-10-16，「怎么跟文献对应上」的深化设计）

> 本节回答两个问题：① 文献表型/指标与我们的队列之间怎么「对应上」；② 这套做法科学上站不站得住。原料 = 题1 回收的 7 份证据 JSON（`outputs/20261016-云端调研_症状关联与小样本方法学/results/`），其中 PMC13638262 原文细节已逐字段核验（Na Y 2026, DOI 10.1002/lio2.70567）。

### 13.1 三道断层：为什么「对应」不能靠贴文献结论

| 断层 | 文献侧 | 我们侧 | 后果 |
|---|---|---|---|
| **① 定义方式** | Park 2025 气流分型 MT/IT/Mixed = **冠状面速度分布目视判读**（定性分类，单侧症状者评症状侧） | 四主特征为连续量，聚类产连续空间分组 | 簇↔表型的对应必须经过「操作化转译」，而转译规则是我们的假设，不是文献原文 |
| **② 物理条件** | 各研究 BC 不一：Park 用 250 mL/s、入口 25°C/35%RH、稳态吸气、刚性壁共轭传热；其余研究 BC 多未报告 | 项目两套 BC（50:50 分流 / 共同静压自然分流） | WSS/热通量/气流占比的**绝对值强 BC 依赖**，跨文献比数值无效；方向与排序对流量大小相对稳健（层流稳态下流态结构主要由几何决定） |
| **③ 人群** | 症状关联证据集中于 ENS 术后人群（Park/Li/Maza）与阻塞人群（Casey/Dupilumab） | 队列为副鼻窦 CT，诊断构成未明（DICOM 仅见协议名 "Head^07_Sinus (Adult)"，无诊断字段） | 映射效度的根本限制：ENS 表型（腔体过大/下鼻道优势）在非术后队列可能不存在或罕见 |

**另一条已核实的口径差**：Park 的鼻阻力定义为 Δp÷体积流量（Pa·s/mL）、患者层面双侧合并——与本项目 R 口径不同，且双侧合并已被 Garcia（PMC3490502）证明会稀释效应（健侧稀释患侧）。任何跨文献阻力对比一律无效，只允许各自内部的方向报告。

### 13.2 三级对应 + 强度分级（桥接协议核心）

**L1 指标对应（连续量 ↔ 连续量）**——逐指标检查定义同构性（测量截面、归一化方式、区域定义）：

| 我们的特征 | 文献对应 | 同构性 |
|---|---|---|
| 黏膜热通量 SAHF50（>50W/m² 面积占比） | Sullivan 2014 SAHF50（n=10, NOSE r=-0.76）；Almagribi 2024 综述合并 r=0.78（预印本，降权） | 截面定义需复核（原文阈值法）；方向可比 |
| 下鼻道峰值 WSS | Li 2018 下鼻甲周围峰值 WSS（n=27, ENS6Q r=-0.398, p=0.003）；Maza 2018 症状组下鼻道 WSS 更低 | **区域定义必须一致（下鼻道周围峰值，非全局均值）**；方向可比 |
| 中鼻道气流占比 | Casey 2017（n=30, \|r\|=0.76）；Dupilumab 队列中/上鼻道 CSA/AFR（n=12, r=0.41–0.49） | 占比定义需归一化口径统一；方向可比 |
| 鼻腔前端温降 ΔT | 鼻中隔偏曲 42 例（VAS R²=0.62）；Zhao 2012 峰值冷却（n=22 健康, r=-0.46） | 位置定义（前端/峰值）需操作化；方向可比 |

**L2 表型对应（簇 ↔ 文献表型）**——操作化近似，允许三种结果：**部分匹配 / 混合匹配 / 未匹配**。示例：Park 的 Group IT（下鼻道优势）→ 我们的操作化假设「下鼻道气流占比 > 50%」（该阈值判据为我们的转译假设，需以原文目视分型的可复现性复核，未复核前标 B 级）。

**L3 症状关联对应（文献 r → 簇症状倾向）**——**只转译方向与显著性状态，不转译数值**。示例：下鼻道峰值 WSS 低的簇 → 转写「该表型在 Li 2018（n=27）中对应更高 ENS6Q 方向（r=-0.398, p=0.003）」→ 禁止写成「该簇 ENS6Q 预计高 X 分」。

**强度分级（每对对应必标）**：
- **A** = 定义同构（截面/归一化/BC 可比）→ 可比数值
- **B** = 操作化近似 → 只比方向
- **C** = 仅概念相关 → 仅作背景，不产症状陈述

### 13.3 命名-映射分离（防循环论证）

表型命名规则**只用描述性/结构性文献**（气流分布定义、几何分型），且在**不看任何症状关联数据前冻结**；症状映射**只用关联性文献**（报告 r 值的队列）。两条文献链分离——防止「按症状关联挑簇、再用症状关联解释簇」的循环。命名时无法对应的簇如实报告「未匹配表型」，禁止为凑对应而放宽命名规则。

### 13.4 数值迁移禁令（硬规则）

任何 Pa / W/m² / ℃ / mm⁻¹ 量级的绝对值**不得跨 BC 直接对标文献阈值**——包括 Zhao 组的 WSS 0.72 Pa（鼻中隔穿孔 87% 敏/100% 特）、Park 的 SAVR 值、任何热通量阈值判定。文献阈值只能以「该值的测量 BC」复现后才可比；未复现 = 仅记录为背景。本队列的 WSS/热通量绝对值只进队列内百分位与锚点偏离（对文献健康锚点，且锚点比较同样受 BC 限制，须声明）。

### 13.5 S4 的科学性评估

**定位（唯一诚实的位置）**：S4 是**假说生成**（hypothesis-generating），不是验证（confirmatory）。症状侧零标签意味着统计推断在数学上不成立——S4 的科学性不来自 p 值，来自以下四支柱：

1. **表型可复现性**：bootstrap 稳定性（ARI/Jaccard≥0.75 才接受 k）+ 留一特征重聚一致性 + 将来新病例落簇率（目标 ≥80%）。可复现的表型是 S4 全部 claim 的地基。
2. **映射透明性**：每条症状陈述可追溯到具体文献的具体数字（源/n/r/证据等级随报告附录）；「原文报告」与「我们的映射/推断」显式分栏。
3. **反例纳入**：题1 的阴性证据（Park 全局阴性 n=14、Cherobin n=25 阴性、器械侧 NAR-症状 r≈0.1–0.4）必须进报告——只报阳性证据的映射层不具科学性。
4. **多源支持门槛**：同一表型-症状方向有 ≥2 个独立文献源才标「多源支持」（如下鼻道低 WSS→ENS 方向有 Li+Maza 两源）；单源一律标「单源，探索性」（Park 的表型-ENS6Q 名义 p=0.047 即此级）。

**方法论依据**：S4 的「变量组合」形态响应 Kimbell/Garcia 综述的领域共识——单一 CFD 变量不足以对应症状，相关建立在变量组合上（这正是全局单指标阴性而分区/组合可阳性的解释）。聚类是变量组合的自然实现。

**已知硬伤与缓解**：
- n=24 聚类不稳定 → **预案**：稳定性判据不过时，S4 降级为「连续特征百分位报告」（不硬分类，仅报告每主特征的队列百分位 + 文献方向偏离），宁可不分类也不报不稳的簇；
- 人群断层 → 队列诊断构成核实列为 A 阶段前置动作；若以鼻窦炎/阻塞为主，ENS 表型映射降为概念参考（C 级），主力映射转向阻塞型证据（MCA/下鼻甲类，在鼻窦队列更常见）；
- 证据本身弱（r≈0.4 级/名义显著）→ 产出形态为**排序假说清单**而非结论清单，按多源状态 × 证据等级 × 效应量排序。

**可失败性（S4 判不成立的条件，预注册）**：
1. 全部 k 的 bootstrap 稳定性 <0.75 → 聚类维度失败，S4 降级为 S1 百分位报告；
2. 表型与 S3 几何表型或客观量（R 百分位）系统性矛盾且无解释 → 映射层可信度崩塌，回退重设计；
3. 映射文献经不起复核（DOI/n/效应量错误）→ 该条映射立即撤下；
4. 将来新病例落簇率 <80% → 表型无泛化性，S4 关闭。
