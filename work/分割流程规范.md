# 鼻腔气道分割流水线规范（专家在环 · 解剖先验）

> 版本：2026-10-01 ｜ 替代旧纯几何路线（grow_nasal 矩形护栏 / calib 面积导数定鼻孔）
> 适用：4 例 CT（例0 锚点 + 患者1/2/3），服务鼻腔 CFD 气流仿真。

---

## 0. 总原则

- 纯阈值 / 纯几何已被三例交叉验证证伪，**不能**分离鼻腔与口腔 / 上颌窦 / 筛窦。
- 本规范为**专家在环的解剖先验分割**：模型初分割 + 人在环修正 + 多标签几何 + CFD。
- 对称比、bbox 捕获率、50–70 mm 跨度**仅作提示**，不再作为鼻腔正确性判据。
- 中间结果一律带几何信息（NRRD/VTK + manifest），最后才导 STL。

---

## 1. 初始语义分割

- 用 **TotalSegmentator `head_glands_cavities`** 预训练模型。
- 取 `nasal_cavity_left`、`nasal_cavity_right`、`nasopharynx` 三标签，合并为**主鼻腔气道**。
- 用 **HU < −300 的空气候选区**限制模型结果，防止模型把组织误标为空气。

## 2. 补鼻孔入口

- 模型可能未完整覆盖**鼻前庭**（vestibule）。
- 用已有鼻孔平面，在空气候选区内**向前延伸**到左右鼻孔。
- 该平面用于**切断外部空气连接**；**最终 CFD 入口面必须保持开放，不得封帽**。

## 3. 分离口腔

- 在**软腭 / 口咽连接处**建立人工排除屏障。
- 保留**鼻后孔 → 鼻咽出口**段。
- **不**用「最大连通域」判断鼻腔（口腔后方经鼻咽与鼻腔相连，靠连通域分不开）。

## 4. 处理鼻窦（双几何版本）

- **G_main**：在上颌窦、筛窦等自然开口处加屏障 → 主鼻腔。
- **G_sinus**：保留 CT 上**确认连通**的鼻窦开口。
- 每个开口必须记录为 **open / closed / unknown**，**不由算法自动猜**；缺判时标 unknown 交 ENT 确认。

## 5. 人工复核（每例 7 点）

- 左右鼻孔
- 鼻阀（nasal valve）
- 鼻甲（turbinate）间隙
- 嗅裂（olfactory cleft）
- 后鼻孔 / 鼻咽
- 鼻窦自然开口
- 是否误连口腔

## 6. 输出标签与格式

标签集（带几何信息）：
```
main_nasal_airway      主鼻腔气道
nasal_sinus_branch     鼻腔-鼻窦分支
oral_excluded          口腔（排除）
nostril_L              左鼻孔入口
nostril_R              右鼻孔入口
nasopharynx_outlet     鼻咽出口
sinus_ostia_status     鼻窦开口状态（open/closed/unknown 清单）
```
- 中间：**NRRD / VTK + manifest.json**（单位 mm、4×4 仿射、坐标系、开口状态清单）。
- 最后才导 **STL**（仅作 CFD 交换，附 manifest）。

---

## 7. 验收条件（新）

- 鼻孔 → 鼻咽 **连续**；
- 口腔 **不连通**；
- 鼻窦开口状态 **明确**（无 unknown 遗留或已交 ENT）；
- 入口与出口 **开放**（未封帽）；
- 标签内 **无 HU>0 组织**（HU 纯净度 = 0）；
- 三向切片（轴/冠/矢）**人工复核通过**。

> 对称比、bbox 捕获率、50–70 mm 跨度仅作提示，不参与上述判定。

## 9. TS 权重失败时的兜底（当前生效）

若 TotalSegmentator 权重**持续无法下载**（代理断连），4 例最现实替代：
> **3D Slicer 中人工放左右鼻腔种子 + 绘制口腔/鼻窦屏障 + Grow from Seeds。**

这不是失败的自动化，而是当前数据量下**可审计、可复现**的专家在环方案，仍满足本规范第 1–7 步的全部验收条件。
