# 三维标定方案：让"切在哪"变成可确认、可复核、可复现

> 起因：操作中"具体位置难以确认，从而无法进行精细操作"
> 结论来源：本机实测（394 层 0.35mm CT，bone/soft 双序列）
> 日期：2026-09-28

---

## 零、先说答案

**可以提前标定，而且标定就是这件事的正确解法。** 但标定的对象不是"物理坐标"——那部分
DICOM 头里已经有了、而且质量极好。真正要标定的是**解剖锚点**：把"鼻孔平面""鼻腔峰值"
"鼻咽过渡"这些**解剖名字**，钉死成**确定的体素坐标**。

有了它，所有操作从"z=172 这层"改写成"距鼻孔平面 X mm"，才能跨病例复用、才能被复核。

| 项 | 值 | 评价 |

## 二、解剖标定：用"体内空气剖面"定位，不靠肉眼翻层

### 2.1 走过的弯路（记录下来避免重犯）

**弯路一：靠"最大 3D 连通域"找鼻腔 —— 失败**

实测：最大连通域 **38,240,313 体素，跨越整个 512³ 体积**（z 0–393、x 0–511、y 0–511）。
体外空气 + 鼻腔 + 咽部 + **气管是同一块连通区域**。

> **这不是 bug，是事实**：空气在人体内从鼻腔一路通到肺，在断层上从未中断。
> **靠连通性永远分不出鼻腔。必须先按解剖平面切割。**

**弯路二：靠"空气面积/导数"定鼻孔 —— 失败**

在 ROI 框内，z<95 处体外空气仍有 1.5 万体素/层，形成低位平台，
导数法把 z=0（扫描边界）误判为鼻孔入口。

### 2.2 正确判据：体外 vs 体内空气

**物理事实**：体外空气与图像边缘连通；体内空气被皮肤/骨/软组织包围。

做法：对每层空气做连通域标记，**与图像四边接触的连通域 = 体外空气**，其余 = 体内空气。

实测结果：体外 **35,778,404** / 体内 **2,829,296**。

### 2.3 标定结果

在"体内空气"上重做面积剖面，得到解剖上自洽的拐点：

| 锚点 | z 层 | 毫米 z | 含义 |
|---|---|---|---|
| **鼻孔入口** | **62** | −682.09 | 面积上升沿起点 |
| 最宽层 | 132 | −657.59 | 鼻腔段 x 跨度最大 |
| **鼻腔峰值** | **146** | −652.69 | 横截面积最大（鼻甲区） |
| **鼻咽过渡** | **208** | −630.99 | 最强下降沿 |

**鼻腔跨度 = 51.10 mm。**

> **这个数字本身就是标定正确性的独立验证**：成人鼻腔长度解剖学上约 5–7 cm。
> 51.1 mm 落在区间内。若标定错误，不可能恰好落在这个范围。

## 三、修正后的诊断：v9 为什么失败

（详见 `work/01_inspect/v9分割失效诊断报告.md`，此处只列要点）

v9 **每层都能正确识别鼻腔主体**（7.7 万–8.9 万体素、质心 x≈250–255），
但被三条判据稳定拒掉：

| 判据 | v9 值 | 实测鼻腔主体 | 问题 |
|---|---|---|---|
| `max_size` | **8000** | **77,000–89,000** | **量级差 10 倍** |
| `触边` | 剔除 | 鼻腔必然触边（连到咽部/气管） | **与解剖事实冲突** |
| `aspect` | ≥1.4 | 恒为 **1.00** | 对主体无分辨力 |

结果：**保留了鼻中隔旁的窄缝（size 2000–7000），丢弃了真正的鼻腔。**

**量化后果**：
- 左右对称比 **0.175**（左 302,834 / 右 53,073，差 5.7 倍）
- bbox 内空气捕获率 **0.4128**（**漏掉 59%**）
- 掩膜 HU 纯净度 `frac_above_0 = 0.0` ✅（这部分没问题）

> **更正一处我先前的误判**：我曾看图认为"红色压在鼻中隔组织上"。
> HU 核查证明掩膜 100% 是空气，无组织混入。红色确实在鼻中隔**旁的窄缝**里，
> 而非压在组织上。**判断错了要改。**

## 四、可复用的方法论

### 4.1 定位解剖平面的通用流程

```
1. 读 DICOM → 确认 spacing / IPP / IOP / RescaleIntercept
2. 阈值取空气 (HU < -300)
3. 【关键】每层连通域标记 → 与图像边缘接触的 = 体外空气 → 剔除
4. 在"体内空气"上做逐层面积剖面
5. 用平滑后面积的导数找拐点：
     上升沿起点 = 鼻孔入口
     上升沿后的最大 = 鼻腔峰值（鼻甲区）
     峰值后最强下降沿 = 鼻咽过渡
6. 交叉验证：鼻腔跨度应在 50–70 mm
```

### 4.2 五个必须遵守的约束

1. **不要用"最大连通域"找鼻腔**——它与体外空气、气管连成一片。
2. **不要用"触边"作排除判据**——鼻腔必然触边。
3. **不要硬编码 z/x 魔数**——所有位置写成"距锚点 X mm"。
4. **必须做交叉验证**——鼻腔长度、左右对称比、x 质心都是可利用的物理约束。
5. **标定结果必须目视复核**——数字对了不等于解剖对了。

### 4.3 质量闸门（每次分割都该输出）

| 指标 | 含义 | 合格线 |
|---|---|---|
| 左右对称比 | min(左,右)/max(左,右) | **≥ 0.7** |
| bbox 捕获率 | 掩膜 / bbox 内空气 | **≥ 0.9** |
| 掩膜 HU 纯净度 | `frac(HU > 0)` | **= 0** |
| 鼻腔跨度 | 鼻咽过渡 − 鼻孔入口 | **50–70 mm** |

> 这四项**只要有一项不合格就不该进入下一步**。当前 v9 在对称比（0.175）
> 和捕获率（0.41）上双双失败。
