# 18 Pa 与边界条件修订

更新：2026-10-02。本文修正历史 `04_cfd_ready/18Pa溯源.md` 中的物理解读，保留录屏字段作为待复现材料，不改变原始录屏。

## 本轮明确修正

1. **给定流量入口 + 单个压力出口有效。**固定15 L/min并指定出口0 Pa或18 Pa，本身不构成过约束。在固定几何、常物性、无额外压力依赖的不可压缩问题中，只改变这一压力参考常数通常改变压力零点；不能把出口绝对表压当作同值跨鼻腔压降。过约束风险在于已经给定完整压力驱动条件，又额外强制同一总流量。
2. **18 Pa = 0.18355 cmH₂O，约0.184 cmH₂O。**历史记录的1.8 cmH₂O差一个数量级。
3. **入口0 Pa总压、出口+18 Pa静压，不等于吸气静压差+18 Pa。**总压和静压不同，压力正负号也不能忽略。保留为独立的录屏复现工况；求解时核对有符号通量，不预先承诺其流向。
4. **出口0 Pa可以是计算压力参考。**这不证明鼻咽在生理上直接通向大气。中文“正常出气口”仅凭措辞也无法唯一确定压力边界。
5. **左右等分与自然分流必须区分。**分别设7.5 L/min会强制等分；把两个鼻孔合成一个均匀流速patch通常也不能代表按左右阻力自然分配。主工况预定用两鼻孔共用可调静压、出口0 Pa，外层调压使求解总流量达到15 L/min。总流量是外层目标，不再作为同时施加的PDE边界。

## 自动配置中的区分

- `total_flow`：目标15 L/min；自然分流的求解适配器尚待实现和验证。
- `total_flow` + `imposed_equal_split_baseline`：明确的人为等分对照，不作为患者真实左右分流。
- `static_pressure_difference`：鼻孔静压减鼻咽静压为18 Pa，流量由求解得到。
- `recording_total0_staticplus18`：保留录屏0 total/+18 static字段，检查实际方向；与上项分开。

具体配置名和状态以 `config_catalog.json` 为准。当前全部患者配置的 `execution_allowed` 为false；无人完成解剖审核时，不自动解除这一状态。

## 压力与湍流字段

OpenFOAM不可压缩结果中的`p`可能为运动学压力，单位m²/s²。必须根据字段dimensions识别，再乘密度ρ转换为Pa；不可只按文件名猜单位。`p_rgh`还需重建静水项，当前简单转换函数拒绝直接处理。

层流没有所用模型意义下的湍流强度字段，输出null/不适用。SST由k与U计算的强度是模型量；在低速点屏蔽，并把无量纲比值乘100后显示百分数，不能填零伪装缺失数据。

## 本机非患者对照验证

2026-10-02，在独立复制的 3,200 单元平行板通道上完成匹配的 0 / +18 Pa 出口参考对照。两组入口固定同一速度剖面，数值设置一致，仅出口压力值不同，均满足 SIMPLE 停止条件。

入口面积平均静压从 0.215879249155 Pa 变为 18.215879249160 Pa；压降分别为 0.215879249155 Pa 和 0.215879249160 Pa。全部对应单元的压力平均平移约 18 Pa，偏离均匀平移的最大差为 9.96×10⁻¹¹ Pa；速度矢量相对 L2 差约 3.93×10⁻¹¹。

对照组采用相同的 10⁻¹⁰ 线性容差，并保留原较严格基准。初次单独试验在更严格容差下遭遇精度下限后被停止，其记录不计为收敛。比较使用原始双精度字段。详见 `solver_reference/pressure_reference_shift/压力参考平移实测.md` 和同目录 `pressure_shift_comparison.json`。

这是固定流量、恒物性不可压缩理想通道的实测支持，不验证录屏的双压力驱动边界、患者解剖或临床准确性。
