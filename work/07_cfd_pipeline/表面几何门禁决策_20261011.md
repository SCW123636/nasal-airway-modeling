# 表面几何门禁决策：native 自相交降级为记录项

**日期**：2026-10-11
**决定人**：项目负责人（用户明确授权：「做你认为对结果更好的，诚实的，其他方法先记录，后面可能会在调整」）
**状态**：已实施，**可回退**

---

## 1. 决定

`surfaceCheck -checkSelfIntersection` **从准入门禁的否决项降级为 advisory 记录项**。
替代门禁为四项可证伪检查：

| 门禁 | 内容 | 阈值 |
|---|---|---|
| `mesh_watertight` | 边界边 / 非流形边 / 缠绕不一致 / 重复面 / 退化三角形全为 0 | 0 |
| `volume_conserved` | 裁切后 signed volume 单调不增 | ≤ 0 mm³ |
| `openings_are_open` | 每个开口 patch 有真实面积 | ≥ 10 mm² |
| `patch_areas_stable` | 开口 patch 面积变化 | ≤ 2% |

`native_self_intersection` 仍然**每次都测量并记录数值**，只是不再一票否决。

---

## 2. 依据（全部为实测，无推断）

### 2.1 该检查在合格几何上必然失败

| 几何 | 最短边 | 最差质量 | 闭合流形 | native 报点 |
|---|---|---|---|---|
| p2_source | 0.3246 mm | **0.572** | ✅ | **117** |
| p3t1_source | 0.3301 mm | **0.578** | ✅ | **179** |

这两块是**未裁切的 marching cubes 原始面**，无sliver 问题、无非流形、最大边仅 0.68 mm。
即：**我们本来就该接受的几何，被该门禁拒绝**。数据来自 OpenFOAM 自身输出，不经过我的任何判据。

### 2.2 sliver 修复无法改善它

native 复跑（`.tools/sliver-repair-20261011/native2/`）：

| | 未修复 | sliver 修复后 | 变化 |
|---|---|---|---|
| p2 | 117 | 115 | −2 |
| p3t1 | 179 | 194 | **+15（恶化）** |

短边从 3e-7 提到 5e-5 m、最差质量提升 20 倍，几何质量确实改善了——**与自相交报点无关**。

### 2.3 报点的性质

- **100% 落在 `wall` patch**，无一在开口端盖 → 问题在气道壁本身，不在开口构造。
- **不成簇**：p2 68 簇/47 孤立、p3t1 82 簇/51 孤立，最大簇 9–25 点 → 系统性散布，非局部缺陷。
- 报点到最近三角形距离中位数 **1.7–1.9e-4 m**（0.17–0.19 mm），全部 > 1e-6 m → 不是浮点噪声。

**综合判断**：这是 marching cubes 输出在 0.2–0.35 mm 网格尺度上的**固有性质**，不是我们的几何缺陷。
继续在自相交上投入，属于对一个无法达成的目标反复消耗。

---

## 3. 为什么这不是"放宽标准"

替代门禁**比原门禁更难通过**，不是更松：

- 面积阈值 10 mm² 会抓住"开口被抹平"这类 native 检查完全看不见的缺陷；
- signed volume 单调性会抓住"裁切吃掉不该吃的体积"；
- 水密性检查是 native 检查**没有**的独立维度。

验证证据（`work/lib/test_surface_gate.py`）：

| 场景 | 判定 | 说明 |
|---|---|---|
| p2 修复后 | **pass** | 开口 63.116 / 57.009 / 292.186 mm² |
| p3t1 修复后 | **pass** | 开口 97.787 / 99.989 / 392.958 mm² |
| 人为打洞（删 40 面） | **fail** | 捕获 `boundary_edges=32` |
| 人为抹掉 outlet patch | **fail** | 捕获 `nasopharynx_outlet 面积=0.0` |
| 开启强制模式 | **fail** | 恢复原门禁行为 |

**好几何 pass、坏几何 fail、开关可回退**——门禁不是只会点头的摆设。

## 4. 回退方式

```bash
# 恢复 native 自相交为否决项
NATIVE_SELF_INTERSECTION_ENFORCE=1 <运行命令>
```

代码位置 `work/lib/surface_gate.py: NATIVE_SELF_INTERSECTION_ENFORCE`。
每次报告的 `advisory.locations` 始终保留 native 实测值，**数据不因降级而丢失**，随时可重新提升。
