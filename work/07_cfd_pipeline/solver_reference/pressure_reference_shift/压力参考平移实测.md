# 固定流量下出口压力参考平移：非患者实测

本轮比较新建的0/18 Pa匹配数值设置对照组。两组均复制已验证中网格，并统一采用压力/速度线性容差1e−10、SIMPLE停止p=1e−8、U=1e−6。它不是与原verified基线仅改一处的比较；但在本对照组内部，输入hash证明只有0/p出口压力值不同。原verified文件未改。

全部3200个同序单元的压力平均平移18.000000000004 Pa，偏离均匀18 Pa的最大误差为9.960e-11 Pa。速度矢量最大差为3.762e-11 m/s，相对L2差为3.927e-11。压降相对差为2.112e-11。

以上使用原始OpenFOAM双精度ASCII字段，避免VTK导出float32后对较大压力偏置的量化影响。零流量差或零波动均按已保存数据精度解释。

平移算例自动SIMPLE停止条件满足：True；末迭代数244；末20步压降相对范围5.559e-11。

最初的严格设置试验使用1e−12压力线性容差，出现约4.5e−12数值精度下限和每步1000次压力内迭代，已定向停止并保留日志。随后另建上述匹配对照，两侧同设容差；没有改动原verified参考，也没有把被停止的初次试验伪装成SIMPLE收敛。

适用范围仅为本次常物性、不可压缩、理想通道、固定入口流量、唯一出口压力参考。它说明在这些条件下出口参考平移不会产生独立的新压降约束。不能推广到录屏中“入口总压0 + 出口静压+18 Pa”的双压力驱动设置，更不能用作患者几何或吸气方向验收。
