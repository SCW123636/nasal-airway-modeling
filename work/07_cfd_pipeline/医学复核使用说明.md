# 医学复核使用说明

## 你导出材料

1. 双击项目根目录的 `打开鼻腔建模工作台.cmd`，或桌面的“鼻腔建模工作台”。
2. 点击顶栏“导出医学复核包”，勾选一个或多个病例；“全选病例”可一次选择全部。
3. 勾选“切片点位复核”和/或“边界与后续人工核验”，核对材料总数，点击导出。
4. 单份直接下载 HTML；多份下载一个 ZIP 压缩包。将文件交给医学复核人，多份先解压再逐份打开。图像已包含在 HTML 中，复核人无需安装项目软件或联网。

## 医学复核人逐项反馈

1. 用电脑浏览器打开 HTML，填写复核人姓名。
2. 逐项查看图像，选择“通过”“不通过”“需要调整”“无法判断 / 证据不足”或“未审核”，填写意见。
3. 不通过或需要调整时须填写修改建议。点位需要调整时填写完整 LPS/mm 建议坐标；法向可留空或填写三个有效值。边界调整使用文字意见。
4. 点击“导出反馈”，将下载的 JSON 文件发回。未审核项会保留在反馈中。

页面会尝试保存本浏览器草稿；更换浏览器或电脑时，可用“导入反馈草稿”继续填写之前导出的 JSON。图像可点击放大。

## 你导回并核对

1. 点击工作台顶栏“导入医学复核反馈”，选择医学复核人提供的 JSON。不同病例与阶段的反馈分别导入。
2. 在“意见核对”中查看每项结论、备注、建议坐标及版本。
3. 对当前版本的点位反馈，勾选准备采用的条目，点击“下载所选审核记录”。
4. 进入“切片审核”，点击“导入审核记录”，导入刚下载的记录并核对。默认只补未审核点位；确需替换已有结论时，勾选覆盖选项。未选条目的本地审核会保留。
5. 上传 CT 病例点击“保存本例审核”；已有扫描使用切片页“下载审核记录”保存审核文件，再按项目原有确认流程处理。

边界意见保存在“意见核对”中，需在边界草稿与后续人工校验中逐项核对后单独确认。导入医学复核反馈不会自动应用裁剪、覆盖候选或批准患者 CFD。

## 当前证据范围

- 反馈绑定导出时的病例、输入、候选和图像版本。材料变化后，旧反馈无法按当前版本导入；已保存反馈显示“已过期”。需重新导出复核。
- 已有扫描的切片包使用当前候选叠加图；只有来源与候选版本均一致的历史 CT/对照图才会附入。p0 的历史对照来源已过期，目前每项附当前候选叠加图。
- 上传 CT 完成点位审核并生成真实边界草稿后，边界包可附三视图、口腔排除、鼻窦排除及开口叠加图。
- 已有扫描暂未接入边界草稿证据；这些项目标记“证据未齐”，只能记录未审核、不通过或证据不足。不能判定通过或调整。
- 最终表面与壁面尚未生成，保留为待补证据项。功能验证通过不代表已完成医学审核；患者 CFD 结果仍为 0。

## 本机存储

上传病例的复核登记与反馈放在其私有病例目录的 `medical_review/`；已有扫描放在病例根目录下的 `existing_reviews/<病例>/medical_review/`。下载的 HTML 和反馈 JSON 含医学图像或审核意见，应按项目影像的同等范围交接，勿加入 Git。
