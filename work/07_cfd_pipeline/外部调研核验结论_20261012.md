## 2. A4：云端抓到我们一个**真缺陷**（已复测定论）

### 2.1 指控成立

`work/lib/locate_native_hits.py:42-45` 测的是报点到**三角形重心**的距离：

```python
centres = verts[tris].mean(axis=1)     # 重心
tree = cKDTree(centres)
d, i = tree.query(pts)                 # 到重心的距离
```

重心是三角形的**内部点**，所以"到重心距"只是"到三角形距"的**上界**：一个正好落在三角形上的点，
照样会测出约三角形内切半径的距离（0.1–0.2 mm）。
→ `自相交定性结论_20261011.md` §5.3「报点到最近三角形距离中位数 1.7–1.9e-4 m，全部 >1e-6 m」
**这条证据无效**，由它得出的"不是浮点噪声"推论不成立。

### 2.2 干净重测（新脚本 + 单点暴力对账）

`work/lib/remeasure_native_hit_distance.py`（Ericson 点-三角形距离，KD 树界定候选但**保证精确**：
`dist(P,T) ≥ d_centroid − r_max`，候选球外可证明不含最近三角形；8/8 自检通过）。
单点探针 `work/lib/probe_one_native_point.py` 对 p2_source#0 做 **220,812 个三角形全量暴力**对账，
与新脚本一致 → 新测距可信。

| case | 报点数 | 真实最近三角形距离 min / median / max | 旧重心距（无效） | ≤1e-9 m | ≤1e-6 m | ≥2 非相邻三角形 |
|---|---|---|---|---|---|---|
| p2_source | 117 | 0 / 1.39e-8 / **3.42e-7** | 1.90e-4 | 31 | **117** | **0** |
| p2_repaired | 115 | 0 / 1.58e-8 / 3.42e-7 | 1.90e-4 | 29 | 115 | **0** |
| p3t1_source | 179 | 0 / 2.35e-7 / 4.42e-7 | 1.66e-4 | 9 | **179** | **0** |
| p3t1_repaired | 194 | 0 / 2.17e-7 / 4.43e-7 | 1.93e-4 | 9 | 194 | **0** |

单点细节（p2_source#0）：最近三角形距离 **8.06e-10 m**（就在其上），第二近 **2.98e-07 m** 且**与它共享一条边（相邻）**，
第三名起直接跳到 **1.697e-04 m** —— 旧指标报的 1.697e-04 正是"到重心"的距离。

**结论**：全部报点都在表面上（≤0.44 µm，即 STL ASCII 量化尺度），但**没有一个是两个非相邻三角形的真交点**。
→ native 报点是**边缘-三角形邻近命中**，不是真穿插。**"伪命中"方向不变，但两条支撑证据必须更换。**

### 2.3 旧 `adjudicate_native_hits.py` 的 75/111 也是错的

其内点投影分支 `d_plane = |n|·clip(n·ap/|n|², 0, 1)` 的量纲是 **m²**（数值 ≈ 2×三角形面积），
与 1e-9 **m** 阈值直接比较；且 clip 到 [0,1] 把所有法向朝背离方向的三角形抹成 0。
实测：对单个报点，旧公式把 **133,859 / 220,812** 个三角形判成"距离 0"。
再加上"精确命中不足 2 个就退化为取最近两个三角形"的 fallback →
§三.3「75/117 与 111/179 确实同时落在两个互不相邻三角形上」**不成立**。
