# 鼻腔 CFD 空气域复核 · 项目方案

> 版本：2026-10-01 ｜ 状态：主线已定，分割引擎待打通
> 一句话定位：基于 CT 的**鼻腔气道三维分割 + CFD 气流仿真**，服务于鼻科手术规划；主体输出为**网页端可拖拽 3D 交互**（流速 / 压力 / 湍流强度三维度）。

---

## 一、要解决的问题（需求鲜明）

1. **鼻腔空气域如何准分割**：纯阈值 / 纯几何已被三例交叉验证证伪（无法分离鼻腔 vs 口腔 / 上颌窦 / 筛窦）。必须走**解剖先验驱动**。
2. **几何保真**：跨软件传递不能丢单位 / 朝向 / 开口语义（STL 单用会丢）。
3. **CFD 边界条件与求解**：入口流量、出口表压、湍流模型必须有可复现、可验收的参数，而非凭经验拍脑袋。
4. **4 例少样本**下的可落地性与不确定性评估。

---

## 二、技术路线（总链路）

```
CT(DICOM)
  → SimpleITK/GDCM 读取（唯一可靠加载器，解 JPEG Lossless）
  → NIfTI/NRRD 体数据 + 标签（保留 4×4 仿射，LPS）
  → TotalSegmentator 预训练初分割（head_glands_cavities）
  → 人在环修正（Scissors / Islands，解剖裁剪面由 ENT 确认）
  → 多标签几何（鼻腔主腔 / 鼻窦 / 口腔 / 鼻孔入口 / 鼻咽出口 / 可疑开口）
  → VTK(.vtp) 表面 + manifest.json（单位/仿射/开口状态清单）
  → CFD 体网格（最后才导 STL 作交换格式）
  → 流量驱动 + 出口 0 Pa 表压 → 层流基线 + SST 敏感性
  → 网页端三 layer 交互交付
```

## 三、三条已实证的铁律（不议）

- **位置来自 DICOM 仿射**：IPP + IOP（行/列方向余弦）+ PixelSpacing；第三轴由 cross(row,col) 得。Δz **必须沿法向反算**，绝不读 `SliceThickness`（实测患者3_t1 标 1.0→实 0.5、患者1 标 1.0→实 0.8、患者2 标 0.75→实 0.5）。
- **各向同性纠偏**：仅例0（0.35³）真各向同性；其余序列实测 1.6×–2.3× 各向异性，**进 CFD 前必须各向同性重采样（0.3–0.4 mm）**。
- **STL 不担中间格式**：不记单位 / 坐标系 / 仿射 / 标签语义 / 开口是否有意保留；只作最终交换，且须附 manifest。MITK 是工具非格式。

## 六、验收标准（验证矩阵）

- 先在**例0 + 患者3_t2** 跑 72 格；收敛达标再解锁例1 / 例2 / 患者3_t1。
- 每格必记：鼻孔–后鼻孔连通性、鼻阀最小面积、鼻窦开口状态、总体积、压降、峰值速度、湍流强度。
- 网格收敛门：粗(0.6)→中(0.4)→细(0.25–0.3 mm)，压降/峰值速度变化 < 5% 视为基本收敛（工程门槛，须经本数据验证）。
- 分割内部验收目标（待真实掩膜回测）：Dice ≥ 0.90、95% Hausdorff ≤ 1 mm、目标开口零漏检——**未被 4 例证明，仅作门槛**。
