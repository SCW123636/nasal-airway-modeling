# v9 分割失效诊断报告

> 对象：`work/lib/segment_v9.py` 在 `work/00_dicom/bone`（394 层 0.35mm ISO）上的实际表现
> 方法：实跑 + 逐层连通域全量枚举（含被拒候选），非推断
> 日期：2026-09-28

---

## 零、结论

**v9 不是"参数需要微调"，是判据体系的方向错了。** 它每层都能正确识别出鼻腔主体（7.7 万–8.9 万体素、质心命中），却用三条判据把它稳定拒掉，转而保留了鼻中隔两侧的碎缝。

| 指标 | 实测 | 应为 |
|---|---|---|
| 左右对称比 | **0.175**（左 302,834 / 右 53,073） | 接近 1.0 |
| bbox 内空气捕获率 | **0.4128**（漏掉 59%） | 接近 1.0 |
| 掩膜 HU 纯净度 | `frac_below_-300 = 1.0`，`frac_above_0 = 0.0` | ✅ 纯净，无组织混入 |

**掩膜里 100% 是空气**——这点没问题。问题是**选错了哪块空气**。

---

## 一、根因：三条判据同时误杀鼻腔主体

逐层枚举显示，每一层都有一个巨型连通域，特征高度一致：

```
z=140  size=77615  cx=250.3  fill=0.296  aspect=1.00  → 触边, 太大, aspect=1.00
z=160  size=83690  cx=252.5  fill=0.319  aspect=1.00  → 触边, 太大, aspect=1.00
z=200  size=87053  cx=250.2  fill=0.332  aspect=1.00  → 触边, 太大, aspect=1.00
z=230  size=80343  cx=254.7  fill=0.325  aspect=1.06  → 触边, 太大, aspect=1.06
```

### 1.1 `max_size = 8000` —— 量级错误

鼻腔主体每层 **77k–89k** 体素，阈值却是 **8000**，差了一个数量级。

被 v9 保留下来的是 `size ≈ 2000–7000` 的域——**这些是鼻中隔两侧的窄缝**，也就是渲染图上那些红色细条的来源。

> 更正一个我先前的误判：我曾看图认为"红色压在鼻中隔组织上"。**这是错的。**
> HU 核查显示掩膜 `frac_above_0 = 0.0`，没有任何组织体素。红色确实是空气，只是它在**鼻中隔旁最窄的缝隙**里，而不是鼻腔主气道。

### 1.2 `触边` 判据 —— 与解剖事实冲突

鼻腔主体连通域与图像边缘接触，被当作"背景/体外空气"剔除。但在这个病例里，**鼻腔 → 鼻咽 → 口咽 → 气管是一条连续气柱**，必然延伸到扫描边界。

**"触边"在鼻腔分割中是正常解剖事实，不是排除条件。** 真正该用来分离"鼻腔内"与"体外"的是**空间位置 + 解剖平面切割**（即 SOP 要求的"在鼻孔平面切断连续性"），而不是"是否触边"这个几何巧合。

### 1.3 `aspect = 1.00` —— 失去分辨力

因为鼻腔主体与咽部、体外空气在断层上连成一片，其包围盒接近正方形，`aspect` 恒为 1.00。这条判据对目标对象**完全无效**。

## 二、`max_fill` 阈值的来历被证伪

v9 文件头注释写：

> 关键洞察：上颌窦的 fill 值 0.48-0.50 与鼻腔 0.17-0.36 有明确分界，
> 把 max_fill 从 0.52 降到 0.42 可以切断泄漏。

实测：

- **鼻腔主体 fill = 0.296 ~ 0.336** ✅ 落在注释说的 "0.17–0.36" 区间内
- 但 `max_fill = 0.42` 并**没有**放过它——因为它先被 `max_size` 和 `触边` 拒了

也就是说：**`max_fill` 这个阈值在筛选一个从未走到它面前的候选。** 注释里"鼻腔 fill 0.17–0.36"的数字很可能来自旧数据上被 `x` 硬边界切碎后的小碎片，而非真实鼻腔主体。**该洞察在当前数据上不成立。**

## 三、判断正确的部分（不要一起推翻）

| 判据 | 结论 | 证据 |
|---|---|---|
| `hu_air_max = -300` | ✅ 正确 | `RescaleIntercept=-1024`，掩膜 HU 中位数 -999 |
| `x_center = 256` 基本准确 | ✅ 可用 | x 分位中位数 252 |
| `x_tol` 排除扫描床 | ✅ 有效 | `cx≈491–495` 的体外空气被正确拒掉 |
| 3D 连通域过滤 | ✅ 方向对 | 16 域 → 保留 2 大域 |
| 左右对称比作为质量指标 | ✅ 该指标本身很有价值 | 正是它暴露了 0.175 的异常 |

## 四、修正方向

**核心思路：从"逐层形态学筛选"转向"先建 3D 气道，再用解剖平面切割"。**

1. **去掉 `max_size` 上限，或提到 10 万以上**。鼻腔主体每层近 9 万体素，这是硬事实。
2. **废弃 `触边` 判据**，改为**3D 连通 + 空间约束**：
   - 先在 3D 上取"与种子点连通的最大空气域"
   - 再按 SOP 要求**在鼻孔平面切割**，切断鼻腔与体外空气的连续性
   - 这一步取代原来靠"触边"的粗暴排除
3. **`aspect` 判据废弃**或只用于小域筛除，对主体无意义。
4. **`max_fill` 重新标定**：若仍要用，阈值必须**在新数据上重新测量**，不能沿用注释里的旧数字。
5. **加入"鼻窦排除"的显式步骤**。当前掩膜虽未混入额窦，但也没有任何机制**主动**排除鼻窦——这需要按 SOP 在窦口最窄处截断。
6. **对称比作为验收闸门**：修正后应达到 0.7 以上（正常人鼻腔左右通气不完全对称，但不应低于此）。

## 六、下一步建议

1. **先做"能看见"的工具，再做"能精确切"的算法。** 当前最大障碍是：参数改了之后，
   没有任何一张图能立刻告诉你"这次切对了没有"。对称比、捕获率这些数字只有在看图之后才有意义。
2. **对称比 + bbox 捕获率应做成每次运行的强制输出**，作为回归闸门。
3. 修正顺序建议：**先做 3D 连通 + 鼻孔平面切割**（解决 59% 漏采），
   再叠加鼻窦排除（额窦/上颌窦/筛窦/蝶窦）。
