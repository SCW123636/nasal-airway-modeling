## 1. 脚本用途

`work/lib/geo_manifest.py`：把分割标签体（NIfTI）转成 CFD 表面，并写出保留全部几何信息的 `manifest.json`。
解决的核心问题：STL/表面文件单独使用会丢失单位、坐标系、原点/仿射、标签语义、开口是否有意保留——manifest 把这些元数据与表面文件绑定交付。

已实现功能：
- `build_affine(spacing, origin, direction)`：通用形式 `A[:3,:3] = direction @ diag(spacing)`，`A[:3,3] = origin`（LPS 轴对齐时退化为对角）。
  - **已用 5 个真实序列核验**：用 `work/01_inspect/affine_summary.json` 的 spacing/origin 重建仿射，与 `manifest_reference.json` 中记录的 `affine_4x4_LPS` 逐位一致（atol=1e-6，5/5 通过）。
- 读标签 NIfTI → 可选各向同性重采样（最近邻，默认 0.35mm，`--resample 0` 关闭）→ 按标签值等值提取二值 mask → 生成表面 → 写 manifest → self-check。
- 复用 `work/lib/dicom_sitk.py` 的 `load_series_sitk`（import 于模块顶部，供上游 DICOM→标签链路共用同一读序列入口）。

## 2. 命令行用法

```
python work/lib/geo_manifest.py \
    --label  path/to/airway_label.nii.gz   # 分割标签体（必填）
    --series-uid 1.2.826.0.1....           # 来源 SeriesInstanceUID（必填）
    --threshold 1                          # 要提取的标签值（等值），默认 1
    --resample 0.35                        # 各向同性重采样间距 mm；0=不重采样
    --out work/04_cfd_ready/case01         # 输出目录
```

## 5. manifest 字段填实情况

已填实（自动）：
- `unit=mm`、`coordinate_system=LPS`（附 RAS 备注）
- `affine_4x4_LPS`：由标签体自身 spacing/origin/direction 重建（方向矩阵为通用形式）
- `input_geometry`（spacing/origin/direction 原样记录）、`resample_spacing_mm` 与重采样后几何
- `threshold_label_value`、`labels_present_in_volume`、`mask_voxel_count_label`
- `source_series_uid`（命令行传入）；脚本会按 UID 在 `work/01_inspect/affine_summary.json` 自动匹配，命中则记录对应真实序列（运行②用例0 UID 验证命中 `例0_Bone_0.35mm`）
- `surface`（路径/格式/占位标志/顶点数或轮廓体素数）

留待人工（写为 null 或 unknown）：
- `smoothing_mm`、`decimation_ratio`：待实际平滑/抽稀执行后回填
- `clip_plane_position`：解剖裁剪面（后鼻孔/鼻咽），须 ENT 确认
- `opening_status_list`：鼻孔 L/R、鼻咽出口、上颌窦/额窦/筛窦/蝶窦开口，全部默认 `unknown`、备注「待 ENT 确认」
