## 共享背景与已验证事实（每个包可独立粘贴，先附这段）

### 项目目标
基于 CT 的鼻腔气道三维分割与 CFD 气流仿真，服务于鼻科手术规划。
流程：CT(DICOM) → 3D Slicer 分割空气域 → Blender/VTK 网格处理 → ParaView/CFD 求解。
交付：网页端可拖拽 3D 交互，输出**流速 / 压力 / 湍流强度**三个维度（"三个 layer"）。

### 已验证的工程事实（实测，非推测）
1. **三维定位原理**：位置来自 DICOM 仿射 —— `ImagePositionPatient`(IPP) + `ImageOrientationPatient`(IOP 行/列方向余弦) + `PixelSpacing`(Δx,Δy)；第三轴(层间法向)由 cross(row,col) 叉乘得到；`SliceThickness` 不可信，Δz 必须由相邻 IPP 沿法向投影差反算（已三方对照验证：ITK GetSpacing = 相邻 IPP 反算 = 全跨度反算，三者一致；标签 SliceThickness 在 3/5 序列上翻车）。ITK/SimpleITK 用 LPS，Slicer 内部转 RAS(x,y 取反)。
2. **数据：共 4 例 CT（已脱敏）**
   - 例0（底座）：某三甲，Philips Incisive CT，**0.35mm 真各向同性**（spacing 0.3496/0.3496/0.35），394 帧×512²，已跑通 DICOM→NIfTI。
   - 例1：市级医院，联影 uCT760，2026-01-27，骨窗 1.0×0.8mm（dz=0.8），面内 0.3477mm，JPEG Lossless P14。
   - 例2：专科三甲，西门子 SOMATOM Definition Flash，2025-09-02，Sinus 0.75 H40s（dz=0.5），面内 0.4590mm，JPEG Lossless P14。
   - 例3：省级三甲，联影 uCT710/968，**双时点**(2025-07 / 2026-02)，0.6×0.6_BONE（dz=0.6），面内 0.3672mm，未压缩 Explicit LE。唯一双时点。
   - 除例0外均有各向异性（例3_t2 0.367²×0.6 为 1.6×；例1 0.348²×0.8 为 2.3×），进 CFD 前需各向同性重采样 0.3–0.4mm。
3. **已证伪（三例交叉验证全失败）**：面积导数定鼻孔入口、对称比≥0.7 判据、替代形态判据（中线±50/左右各一团≥80/鼻中隔带/最大两分量占比）。结论：纯几何/统计**无法**分离鼻腔与口腔/上颌窦/筛窦，差别在解剖语义（鼻甲、嗅裂、鼻阀、鼻窦自然开口连通）。
4. **加载器**：必须用 SimpleITK（内置 GDCM 解 JPEG Lossless）；`RescaleIntercept` 同批有两种值(-1024 vs 0)，必须按序列取，不能写死。
5. **当前分割状态**：TotalSegmentator `head_glands_cavities` 的 step2 权重下载被代理断连，**零掩膜产出**；该 task 19 类仅含 nasal_cavity_left/right、nasopharynx、oropharynx、soft_palate、hard_palate，**无口腔空气标签、无筛窦/蝶窦**。兜底方案（脚本化 Grow-from-Seeds）在例0 实测体积 1635.8 cm³（≈全颅空气）→ **QC FAIL（口腔/鼻窦泄漏）**，HU 纯净度 100%，证明不施加屏障必然淹没整个气腔。
6. **18 Pa 溯源（已查实）**：它是某 CFD 工具在**出口端（鼻咽面）设的 gauge 静压 +18 Pa（参考大气压）**，严格**不是** Δp（入口用的是 0 Pa total pressure，total≠static）。SOP（入口流量 + 鼻咽 0 Pa 表压）与方法记录（"咽喉处为正常出气口"=gauge 0）语义一致；录屏（0→18 Pa 压力边界）是另一种边界类型。
7. **CFD 基线设定（待裁定但建议）**：入口总流量 Q=15 L/min=2.5×10⁻⁴ m³/s；鼻咽出口 0 Pa 表压；阈值主结果 -300 HU，回测 -350/-400；层流主、k-ω SST 敏感；网格 3 档 0.6/0.4/0.25–0.3mm，5% 收敛门。
8. **验证矩阵（已设计）**：3 阈值 × 2 几何版本(G_main/G_sinus) × 3 档网格 × 2 求解 = 36 格/例，先在例0+例3_t2 跑 72 格。

## 需求包 A —— 鼻腔/口腔/鼻窦分离的解剖先验分割方案（最难，核心阻塞）

### 问题
在 **TotalSegmentator 权重不可用 + 仅 4 例** 约束下，如何稳定产出"排除口腔、鼻窦按自然开口可控"的鼻腔气道掩膜？当前兜底（Grow-from-Seeds）因无屏障，鼻腔-口腔-鼻窦-咽腔全连通（例0 实测 1635.8 cm³ FAIL）。需要一套**可审计、可复现、能在 Slicer 或脚本里落地**的分离策略。

### 已掌握（见共享事实 3/5）
- 纯几何/统计特征已证伪，必须走解剖先验。
- TS 单 task 给不出口腔空气、筛窦、蝶窦；需第二 task 或人工。
- 口腔后方经鼻咽与鼻腔相连，**不能靠阈值或连通域大小分**。

### 需要模型输出
1. **屏障/裁剪面设计**：在体素空间里，软腭/口咽连接处、各鼻窦自然开口处，应如何定义排除屏障或解剖裁剪面？给出可计算的几何判据（例如基于骨性硬腭的 HU 阈值 + 形态学、或基于鼻咽通道中轴线的法平面），而不是"请专家手动画"。
2. **种子策略**：左右鼻腔、鼻阈(limen nasi)、鼻腔中段、鼻咽出口的最佳种子位置与数量；口腔/外部空气/不纳入鼻窦的排除种子位置。
3. **双几何版本 G_main / G_sinus 的自动生成判据**：鼻窦开口 open/closed/unknown 如何由各向同性重采样后的局部通道截面积 + HU 连续性判定，而非"算法自动猜"。
4. **质量门（QC）判据**：除我方已有的"鼻孔-鼻咽连续/口腔不连通/无 HU>0/三向切片人工复核"外，给出可量化的自动告警指标（如鼻腔体积合理区间、单侧占比、鼻阀最小截面积下限）。
5. **若 TS 权重恢复**，如何把 TS 初分割 + 上述屏障做人在环修正，给出最小人工干预步骤。

### 验收（回测）方式
- 用例0（真各向同性，最干净）做首验：产出的 main_nasal_airway 体积应落在成人鼻腔合理区间（经验 ~15–40 cm³ 量级，非上千），口腔连通域应为 0，鼻窦开口状态清单明确。
- 对例3_t2（双时点）验证一致性。

## 需求包 B —— CFD 边界条件、18 Pa 解析、网格收敛与湍流模型（领域专家）

### 问题
鼻腔尺度（特征尺寸 1–2mm，鼻阀狭缝更细）下，边界条件与求解设置如何做到**物理自洽且可复现**？尤其 18 Pa 的语义歧义、层流 vs SST 的湍流强度报告矛盾、网格收敛判定。

### 已掌握（见共享事实 6/7）
- 18 Pa = 出口 gauge 静压 +18 Pa（参考大气压），非 Δp；安全默认 = 入口流量 + 鼻咽 0 Pa。
- 入口 15 L/min；阈值 -300；层流主/SST 敏感；网格 3 档。

### 需要模型输出
1. **边界条件严谨化**：若采用"入口给定流量、鼻咽出口 0 Pa 表压"，左右鼻孔分别设入口时流量分配与速度 U=Q/A 的计算；若采用 18 Pa 作为压降，应写成 `p_nostril − p_nasopharynx = 18 Pa` 的压力驱动求解，并说明此时不再同时强制定流量。给出两种设定下速度场/压降场的预期差异量级。
2. **湍流强度报告**：层流模型不提供有物理意义的湍流强度；网页必须显示"湍流强度"时，如何标注（层流结果显式标"无湍流模型/不报湍流强度"，SST 结果报模型计算的湍流强度）。给出 SST 入口湍流强度 1%/5%、湍流长度尺度 ~0.1 Dh 的合理性。
3. **网格收敛**：鼻腔主腔 0.4–0.6mm、鼻阀/鼻甲间隙 0.2–0.3mm、最小水力间隙≥6 单元跨越；SST 棱柱层 8–12 层、增长率~1.2、总厚 0.5–1.0mm，以 y+≈1 检查。论证"压降/峰值速度/流量分配在中→细网格变化<5% 即收敛"是否适用于鼻腔尺度，还是需更严的 2% 或基于网格自适应。
4. **Reynolds 数区间**：安静呼吸下鼻腔 Re 量级估算（用特征尺寸与 15 L/min），判断层流基线是否充分，何时必须 SST。

### 验收（回测）方式
- 用例0 真几何（各向同性 0.35mm）做首验：3 档网格压降/峰值速度变化曲线，判断 5% 门是否达到；SST 与层流的湍流强度差异是否如预期。
- 18 Pa 两种设定（流量驱动 vs 压降驱动）的速度场差异定性对比。
