# 鼻腔气流CFD模拟项目需求文档

本文档面向算法研发人员，系统说明鼻腔气流CFD模拟项目的背景、现状、技术路线与开发需求，作为AI自动分割与仿真流程开发的依据。

# 一、项目背景

## 1\.1 疾病概述

空鼻症（Empty Nose Syndrome，ENS）属于鼻甲过度切除手术诱发的结构性鼻炎。鼻腔解剖结构发生改变后，鼻腔内部气流严重紊乱，患者长期存在鼻腔异常干燥、窒息感、神经刺激等一系列严重症状。当前部分医务人员容易将这类器质性病变简单归类为心理问题，造成大量患者长期无法得到有效诊疗。

## 1\.2 临床痛点

鼻腔填充、鼻腔结构重建等修复方案已经证实能够缓解部分空鼻症患者症状。但是现阶段手术方案高度依靠医生个人临床经验，填充位置、角度、填充剂量缺少客观量化依据，手术效果难以提前预判，大量患者多次手术依旧无法改善不适。

**核心症结：**缺少手段量化鼻腔内部气流力学异常，无法直观展示气流紊乱位置。

## 1\.3 项目目标

打造平民化、低成本鼻腔气流分析工具。

输入患者鼻腔CT、鼻内镜影像，自动重建鼻腔三维模型并开展气流仿真，直观定位气流紊乱区域；为鼻腔填充、结构重建手术提供客观数据支撑，改变手术"凭经验盲做"的现状，力求依靠数据提升一次手术成功率。

同时搭建沟通载体，让患者借助量化气流数据，与临床医生开展高效、平等的沟通。

# 三、现有技术路线（人工标准流程）

## 3\.1 全流程概述

当前整套项目的基准工作流依靠开源免费工具链，人工完成从CT影像到气流仿真分析全流程：

CT原始DICOM文件 → 3D Slicer人工分割鼻腔气道 → Blender修复三维模型 → SimScale/OpenFOAM流体仿真 → ParaView气流可视化分析

**作用：**作为基准金标准，精确计算鼻腔内部气流速度、压力、壁面剪切应力等关键指标，获取空鼻症患者鼻腔气流异常量化数据。整套流程无需付费商业软件，所有工具开源免费。

**短板：**人工气道分割耗时很长，熟练操作仍需30–60分钟/例；人工边界判断存在主观差异，难以批量处理大量病例。

## 3\.2 关键环节：三维气道分割（3D Slicer）

目标：把鼻腔里空气所在的空间的几何分割出来，是目前流程最耗时的步骤。生成STL的过程目前最麻烦。

**操作要点：**

1. 导入DICOM CT序列，创建Airway气道分割图层；

2. 使用阈值工具初步圈选空气区域（HU值\-1024～\-300，可微调；有技术称\-400，具体根据实际情况分析）；

3. 先用Scissors（剪刀）或Erase（橡皮擦）切断鼻孔处的部分体积，切除很薄的一部分即可，不要影响鼻孔内气道体积（目的是切断鼻腔内部和外部的气道连续性，方便后续删除鼻腔外部空气）；点击Islands工具，选择Keep selected island（保留选中孤岛），在视图中点击鼻腔主气道区域，只保留与点击点连通的那一块；或使用Paint（画笔）/Erase（橡皮擦）手动逐层修正；

4. **ENS患者重点提醒：**下鼻甲切除后鼻腔异常宽大，阈值分割边界容易出错，必须逐层手动修正，必要时对照解剖图谱；鼻甲切除后残留的凹陷、瘢痕腔隙，若与主气道连通且有实际气流通过，计入气道；盲端腔隙排除；

5. **进出口边界规范：**鼻孔保留完整开口，统一以外鼻孔最外缘所在平面为界；鼻咽末端沿冠状面切出平整出口，切割位置统一为软腭游离缘水平（轴位视图中软腭后缘与咽后壁之间的游离软组织下缘）。若团队选择其他解剖标志，必须在《K\-Hub 鼻腔气道标注协议》中写死，所有病例严格执行同一标准。鼻窦（上颌窦/筛窦/额窦/蝶窦）一律排除；窦口引流通道若与主气道连通，在窦口最窄处截断；鼻泪管、咽鼓管开口排除。（如内容有误，以实际情况为准，后期可与已跑通的同志沟通，开线上视频会议交流）

6. 点击Show 3D预览气道立体模型，旋转检查是否有破洞、毛刺、断裂；切换到Segmentations模块，Export to files，格式选STL，得到Airway\.stl。

**后续几何修复：**三维气道分割在视频里不是难点，难点主要是STL几何修复，由Blender完成修复三维模型（修复简化网格过程中出现的点线面问题）。

## 3\.3 隐私安全规范

1. 3D Slicer内置Anonymize匿名化工具清除CT个人信息；

2. 最优方案：直接导出分割完成后的STL几何模型上传，STL不携带任何患者隐私；

3. 特别提醒：CT可三维重建出面部轮廓，即使删除DICOM头信息，面部区域本身也可能构成可识别信息；训练数据建议裁剪至鼻腔ROI，或做面部去识别（defacing）。
