# 鼻腔空气域标定方法 —— 模型检验与优化交接说明

> 文档用途：把当前"从 CT 自动标定鼻腔解剖位置"的方法完整交代清楚，附**可离线验证的数据包**，
> 供另一个更强模型**独立验证正确性**并**提出优化方案**。
> 阅读者假定：具备医学影像/Python/NumPy 基础，但不了解本项目历史。本文档自包含。
> 配套数据见文末「文件索引」。

---

## 0. 一句话方法

**用 CT 的 HU 阈值认出全部空气 → 用"是否从图像边缘可达"把空气分成体内/体外 → 对体内空气沿 z 做面积剖面、用导数找解剖拐点 → 把鼻孔入口/鼻腔峰值/鼻咽过渡钉成确定的层号。**
所有结果只依赖原始 DICOM，不依赖任何人工标注或预分割。

---

## 1. 目标与最终目的

- **直接目的**：在 394 层鼻腔 CT 上，自动给出"鼻孔平面""鼻腔最宽处""鼻咽过渡"的确定位置，
  使后续一切切割/分割操作都写成"距鼻孔入口 X mm"，而非"第 175–292 列、第 120–260 层"这类与解剖无关的魔数。
- **最终目的**：为鼻腔 CFD（计算流体力学）气流仿真提供**可定位、可复核、可复现**的空气域，
  支撑鼻腔填充/结构重建手术的客观量化（把"吸不到气"这类主观主诉变成可左右对比、前后对比的数字）。
- **本阶段交付物**：解剖锚点（层号+毫米坐标）+ 交互式复核页 + 可复现脚本。
  **尚未交付**纯鼻腔分割掩膜（见第 7 节局限）。

## 4. 核心算法（精确描述 + 参数）

### 4.1 体内/体外空气分离

```python
air    = vol < -300                       # HU 阈值：空气≈-1000，组织>-300
outside = zeros_like(air)
for z in range(nz):                       # 逐层(2D)处理
    a = air[z]
    lbl, n = ndimage.label(a, structure=ones((3,3)))      # 4连通标连通域
    edge = lbl[0,:] | lbl[-1,:] | lbl[:,0] | lbl[:,−1]    # 接触四边的标签
    outside[z] = isin(lbl, edge_labels)
inside = air & (~outside)                 # 被组织包围的空气 = 体内
```

- **判据本质**：体外空气从图像边缘 flood fill 可达；鼻腔/口腔/咽空气被皮肤骨组织包围，不可达。
- **参数**：空气阈值 `-300 HU`；连通性 `3×3`（2D 4 邻域）。
- **本例结果**：体外 35,778,404 体素 / 体内 2,829,296 体素（体内占全部空气 7.3%）。
- **验证**：渲染显示红层完整覆盖两个鼻腔+鼻咽，蓝层在头部轮廓外，分离干净。

### 4.2 锚点检测（面积剖面 + 导数拐点）

```python
prof = [ inside[z].sum() for z in range(nz) ]   # 逐层体内空气体素数
ps   = smooth(prof, 9)                            # 平滑(k=9 均值)
dps  = gradient(ps)                               # 变化率
z_lo = first z where prof>0
search_from = z_lo + 15                           # 跳过起始伪影
i_rise = search_from + argmax(dps[search_from:]) # 最强上升沿
i = i_rise
while i>search_from and dps[i]>0: i -= 1         # 回退到上升沿起点
z_nostril = i                                     # 鼻孔入口
z_peak    = z_nostril + argmax(ps[z_nostril:])    # 鼻腔峰值(最宽面积)
i_fall    = z_peak + argmin(dps[z_peak:])         # 鼻咽过渡(最强下降沿)
z_widest  = z_nostril + argmax(x_span[z_nostril:z_peak+1])
```

- **判据本质**：鼻腔沿 z 的空气面积呈"低平→陡升→平台→陡降→低平"，拐点对应解剖边界。
- **关键参数**：平滑窗 `k=9`、起始跳过的 `search_from = z_lo+15`（避免 z=0 附近扫描截断伪影被误判为鼻孔）。
- **当前结果（已独立复现，diff=0）**：

| 锚点 | z 层 | 毫米 z (= origin_z + z·dz) | 含义 |
|---|---|---|---|
| 鼻孔入口 `z_nostril_entry` | 62 | −682.09 | 面积上升沿起点 |
| 最宽 `z_widest` | 132 | −657.59 | 鼻腔 x 跨度最大层 |
| 鼻腔峰值 `z_nasal_peak` | 146 | −652.69 | 横截面积最大层 |
| 鼻咽过渡 `z_nasopharynx` | 208 | −630.99 | 最强下降沿 |
| **鼻腔跨度** | — | **51.10 mm** | (208−62)·0.35 |

- **正确性佐证**：成人鼻腔真实长度 50–70 mm，标定得 51.10 mm，落在区间内（非证明，是强相关证据）。

## 6. 已验证 / 未验证（诚实分层，请勿混用）

**✅ 已验证（有实测证据）**
- 物理坐标各向同性 0.35 mm、bone/soft 像素级对齐、无跳层。
- 锚点可由 CT 独立复现（diff=0）。
- 鼻腔跨度落在成人解剖区间。
- v9 掩膜 `frac_below_-300=1.0`、`frac_above_0=0.0` → **100% 空气**，无组织混入；问题在"选错空气块"而非"混入组织"。
- 体内/体外分离在本例视觉干净。

**⚠️ 未验证 / 假设（检验重点）**
- `z_nostril_entry=62` **可能略早**：该层红层主要在口腔区，真鼻孔或更靠后，需人工目视确认。
- **体内空气 ≠ 鼻腔**：红层仍含口腔、咽、鼻窦。要到纯鼻腔还需 z 切割 + 鼻窦排除。
- **flood fill 是逐层 2D**：若头颈贴图像边缘，外部空气会漏入体内吃掉红层；本例未触发，需联调验证。
- **跨病例泛化性：已从"未知"降为"已初步验证，样本仍少"**（见第 12 节）。`calib_multi.py` 已用**同一脚本**自动跑通 3 例（层厚 0.5/0.6/0.8 mm、kernel 各异），鼻腔跨度 33.0–45.6 mm、对称比 0.986–0.998、HU 纯净度 0，**三例全过闸门**。仍缺大样本（如 >20 例、含 ENS 空鼻/解剖变异/儿童）回归。
- CFD 边界条件（SOP 说 入口 15 L/min→出口 0 Pa；录屏用 0→18 Pa 压力边界）、稳态 vs 瞬态未决。

## 7. 已知局限与失效模式（排名）

1. **红层含非鼻腔结构**：口腔腔隙、鼻咽、鼻窦都在体内空气里。锚点只给 z 范围，鼻窦排除（上颌窦/筛窦/蝶窦/额窦靠窦口最窄处连通）未实现。
2. **逐层 2D flood fill 的连通性漏洞**：理论上 3D 体连通 flood fill（从扫描孔背景灌入）更鲁棒。
3. **锚点检测对单病例过拟合嫌疑**：导数拐点法在 z=0 附近有扫描伪影，靠 `search_from=z_lo+15` 硬跳过——换一份数据若伪影形态不同，可能失效。
4. **v9 旧分割的判据体系方向错误**（已证伪，非调参可救）：
   - `max_size=8000` 而真实主体 77k–89k（差 1 数量级）→ 主体被砍，保留鼻中隔碎缝；
   - `触边` 判据与解剖事实冲突（鼻腔气柱本就连通到扫描边界）；
   - `aspect=1.00` 无分辨力。
   - 证据：对称比 0.175（左 302,834 / 右 53,073）、bbox 捕获率 0.4128（漏 59%）。
5. **单入口丢失左右通气信息**：而左右通气失衡是鼻腔手术最关注指标之一。

## 9. 优化目标（具体、有优先级）

- **T1**（最高）：用 3D 连通域 + 鼻孔平面切割，替代逐层 `触边`/`max_size` 筛选，解决 59% 漏采。
- **T2**：鼻窦排除——在窦口最窄处按解剖位置截断（上颌窦/筛窦/蝶窦/额窦）。
- **T3**：把全部硬编码魔数（`x_tol`/`max_size`/z 范围）改为锚点相对量（"距鼻孔 X mm"）。
- **T4**：体内/体外分离改 3D 体连通 flood fill（从扫描孔背景灌入）提升鲁棒性。
- **T5**：多病例回归——锚点检测在 ≥3 例上求召回/误检，定容差。
- **T6**：对称比 + 捕获率做成每次运行的强制验收闸门（目标对称比 ≥0.7）。

## 10. 需人工裁决的开放问题

1. 鼻孔入口 z=62 是否准确（建议复核 z=60–100）。
2. 是否同时用 bone（骨性标志）与 soft（鼻甲/软腭）两套，还是只 bone。
3. CFD 边界条件口径：SOP 流量边界（15 L/min→0 Pa）vs 录屏压力边界（0→18 Pa）——二者算出的物理量不同。
4. 稳态 vs 瞬态：做鼻阻力定量必须用瞬态（呼吸周期），稳态只能看流场形态。

## 11. 跨患者自动化策略（回答"其他患者怎么定位置"）

**核心结论**：标定方法是**零参数确定性算法**，不含任何训练模型、不要求人工标注。所谓"第一次费时间"是**构建/调试**方法的一次性成本；方法锁定后，新患者 = 跑一条固定命令（~1–2 分钟），人只在**闸门报警**时才介入。

### 11.1 为什么换患者不用重写位置

旧分割（v9）把位置写死成 `z∈[120,260]`、`x∈[175,292]` 这类**与解剖无关的魔数**——换患者/换机器立刻失效，这正是"无法精细操作"的根。
本方法不存任何魔数：每次都对**当前 CT** 重算 `vol<-300` → 体内/体外分离 → 面积导数拐点，天然适配不同层厚、不同原点、不同层数。**已实证**（见 12 节证据）：3 例 z 层数 136/286/186、原点各异，算法各自给出正确锚点。

### 11.2 分层 SOP（每次新患者走这条）

```
新患者 CT
  ├─① 自动标定（~1 min，无人）
  │     calib_v2.py 风格脚本 → landmarks.json + 三道闸门值
  ├─② 闸门自动判（无人）
  │     跨度∈解剖范围?  对称比≥0.9?  HU纯净=0?  体外空气占比正常?
  │       ┌──────┴──────┐
  │     全过          有不过
  │       │              │
  │       ▼              ▼
  │    直接进分割      ③人工扫一眼(~2 min)
  │                   只翻 3 个关键层
  │                   (鼻孔入口/峰值/鼻咽过渡)
  │                   确认 or 改一个种子
  └─④ 分割脚本读锚点自动下刀
       (z_nostril 切入口、z_nasopharynx 切出口)
       不再依赖任何手写层号
```

**关键点**：人只出现在异常分支。绝大多数患者①+②即过；只有闸门报警才需 2 分钟肉眼确认三个锚点层。**这跟"每次完整跑一遍 AI"是两回事。**

### 11.4 仍需人工/优化才能全自动的点（给检验模型的靶点）

1. **鼻窦排除未自动**：红层(体内空气)仍含上颌窦/筛窦/蝶窦（靠侧壁窦口连通）。目前靠"z 两刀切"得鼻腔 z 范围，但窦口连通段未自动截断 → 需加窦口位置逻辑或人工点种子。
2. **后段口腔/鼻腔分离未自动**：鼻阈(nasal valve)最窄、最影响鼻阻力，在 z 范围内但未单独锁定。
3. **flood-fill 贴边假设**：头颈贴图像边缘时体外空气漏入体内。需加"体外空气占比异常"预警闸门（参考 `gate`：本例体外占比 92.7%，若骤降即报警）。
4. **扫描协议感知**：不同协议覆盖解剖范围不同，自动判定"跨度是否合理"需按协议分类阈值，而非单一 40–70 mm 硬区间。
